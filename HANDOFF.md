## Хвосты (задач в Trelvis на них нет — завести при случае)

- Живой «Снять → Поставить» Swift-патчером на Маке Элвиса и на чистом пользователе macOS; отзыв первого из команды.
- Поведение обновлений Claude (Squirrel/ShipIt) после ad-hoc подписи — не проверено; `docs/TEAM.md` обещает
  «Поставить снова».
- **Вес `status.json` и `probe-result.json`** — по ~3,9 МБ: лоадер кладёт в них `url` каждой из четырёх десятков
  страниц, а у артефакта `url` это `data:`-адрес целиком. Лечится только правкой лоадера, то есть перепатчем
  у всей команды.
- StatusFeed: подсказка полоски со сводками только там, где есть `~/_ElvisProjects` (`projectsRoot` в claude.json);
  при 9+ проектах хвост списка по алфавиту отбрасывается (32 КБ).
- **Карта тем на странице растёт вдвое**: на чат теперь два ключа (`id:` и тень `chat:`), у localStorage потолка
  нет, уборки нет. У файла потолок есть (32 КБ + 200 ключей).
- **Позиции окон по id чата**: поле `pos` в записи темы зарезервировано и никем не пишется, владелец
  геометрии — WF21. Оценка отдельной работы +1,5 ч.
- `row` активной строки сайдбара в главном окне = null (`myChatId` берётся по пути); адресом поле `chat`
  служит только у команд `theme` и `cashout` (у `popout-window` это груз — какой чат вынести);
  тень `id:` над более полной `chat:` при `themes-restore` (verify WF35);
  безымянный попап («Claude») уносит ключ `main`.
- **Возврат цвета проекта и живых цветов на перезапуск Claude (WF35)** живым гейтом не проверяется:
  `ClaudeApp.onRestart` висит на смене pid **Claude**, и `pkill` приложения его не вызывает вовсе. Закрыто
  Swift-тестами; один ручной перезапуск Claude — на Элвисе.
- **Перенос везёт только вложения ПОЛЯ ВВОДА**: картинки и файлы из ленты разговора не переносятся вовсе (в
  ElvisOS переносились). Полка `window.__myclaudeFiles` живёт в памяти окна — перезагрузка страницы её теряет.
- Lua-модули в `hammerspoon/` — архив, только источник логики: тем и полоски они не знают.
- Настройки Элвиса, которые менял агент 06.09 (сказано ему): `projectPaintEnabled` включён (был 0), `themeAll`
  (violet, «всем окнам») снят — оба глушили цвет проекта.
