# Пимп: редкое

Часть скилла «Пимп» (`SKILL.md` рядом): как звать CLI и правило «окна Claude — только Элвису и Рику» — там.

## Ответы `send` (WF103)

«Отправил в «…»»; «в поле свой текст — не отправил» (текст Элвиса цел, ничего не вставлено); «нет поля ввода»;
«вставил, но не отправилось — текст в поле»; «отправил, но подтверждения нет» (текст мог уйти — повтор не зови,
глянь окно). Окон проекта два — отказ с заголовками, тогда `--chat local_…`.

## Новый чат вместо старого (`renew`, WF102)

«Смени чат в окне Вкуснофф», «открой новый чат на месте этого» — `renew <local_…|проект> --text "<передача>"
[--model "Opus 5.5"] [--effort extra]`: новый чат того же проекта встаёт в рамку старого окна, старое окно
закрывается, когда известен id нового (чат не удаляется). Текст — первым сообщением (длинный — `--text -` со stdin,
до 20 000 знаков); без `--text` — штатный текст нового окна. Ответ «Заменил окно «…» новым чатом local_…» — этот id
и есть новый чат. «модель не встала» — текст ушёл на прежней модели. Главное окно (WF181): новый чат встаёт в нём
самом, второго окна нет, закрепления не трогаются; «чат не опознал» — новое окно открылось, старое осталось: лишнее
закрыть руками, повтор не звать. Идёт до 65 с.

## Перезапуск Claude (`restart-claude`)

Только по прямой просьбе Элвиса. Первой строкой печатает id запроса. Ты сам в окне Claude и погибнешь вместе с ним —
ответ после перезапуска читай из `pimp/<id>.result.json`; синхронный код 0/1 — для внешних вызывающих (PimpViewer).
Идёт ответ в другом чате — отказ, `--force` оборвёт работающие чаты. «Идёт ответ» — кнопка стопа в окне или
транскрипт чата Claude Desktop (`~/.claude/projects`, и субагентов) менялся за 90 с; чат, которого нет в индексе
Claude Desktop, не виден, терминальные `claude` не в счёт.

## Главное окно и главный проект (`main`)

«Перенеси Рика в главное окно» — `main Rick` (или точный `local_…`): прежний главный чат выносится в окно,
выбранный занимает главное. Это смена окон, а не новый чат; вызывай только по просьбе переместить чат.
Не путать с `mainProject` в `claude.json`: папка главного проекта защищает его окна от `hide` и притемнения,
не переносит их в главное окно Claude. Настройка `mainChat` автоматически меняет главное окно после расстановки;
не включай её ради одного переноса. Значение папки берётся из списка проектов, без догадок.

## Раскладка `center` и клетки

| Элвис сказал | вызов |
|---|---|
| «главный по центру», «Рик по центру» | `arrange --layout center` — главный в треть экрана по центру, остальные окна его экрана делят бока поровну; главный — `--center <проект или local_…>`, без ключа — твой чат, нет его — главное окно; порядок боков — `--order` |
| «клетками», «друг под другом», «в столбик», «слева работа, справа хобби» | `center` со стопками: в `--order` запись `A+B` — один столбец, A сверху, B снизу; главный, названный в `--order`, стоит там, где назван |
| «три слева, Рик, три справа, редкие клетками» | `arrange --layout center --center Rick --order VkusnoffKz,Marketolog+VkusUchet,Risovalka+MenuMaker,Rick,PimpViewer,PimpMyClaude,Dictator` |

Клетками ставь чаты, с которыми Элвис говорит реже, парами связанных (кто работа, кто хобби, кто редкий — правило
«Раскладка окон» в `SkilZZZ/ELVIS.md`). В столбец на Одиссее (720) — не больше двух, на вертикальном 1280 — три;
больше — CLI скажет «в столбик влезает не больше N окон». С `--order` и раскладкой `last` выбранная плитка не
слетает: «Вкуснофф первым…» — `arrange --order … --layout last`. Проекты, которых Элвис не назвал, встанут следом,
окна без папки — в хвост. Имя раскладки бери из слов Элвиса как есть.

## Возврат раскладки (`layout restore`)

Идёт долго: окна открываются ПО ОДНОМУ, до 15 с каждое (новые чаты с `--new` — до 65 с), на десяти местах это до
7 минут. **Зови с таймаутом 10 минут (`timeout: 600000`)** — иначе оборвётся твоя оболочка, а не Пимп: он в это
время спокойно открывает окна. Дождись ответа и не повторяй вызов; обрыв оболочки отказом Пимпа не считай и «занят»
в ответ на повтор — тоже. «верни окна на мониторы» — `restore-screens`, не `layout restore`.

## Редкие отказы

- «Не могу запомнить: не знаю, какой чат в окне …» — Пимп не опознал чат окна: передай Элвису как есть,
  включить «Свой цвет у каждого проекта» в «Оформлении» панели PMP он должен сам; сохранять «как получится» нельзя — вернутся не те чаты.
- «Раскладки «…» нет, есть: …» — имя не то; предложи одно из названных, наугад не подставляй.
- «Чат не создан: …» — страница Claude отказала (причина после двоеточия): передай Элвису как есть, повтор — только
  по его слову; «Чат создан, но в окно не вынесся» — вынести руками, новый чат не открывай.
- «На этом наборе мониторов окна ещё не запоминал…» — `restore-screens` вернуть нечего: предложи `arrange`.
- «Окно чата не открылось за 15 с…» — окно не вынеслось; второй `open` не зови (у `--last` — можно повторить `--last`).
- «Последнего чата в этом проекте нет» — Claude переустановлен или проект новый: предложи `open` без `--last`.
- «Главное окно Claude не нашёл — ничего не прятал» (`hide`) — повтори через минуту (карта чатов догонит) или скажи
  Элвису свернуть окна руками.
- «Экран мал…» — столько окон в эту раскладку не влезает: предложи раскладку пореже или ленту («как сейчас»);
  «в раскладке места нет — оставил поверх» — окно открылось, это не отказ. Обе строки бывают только у явных
  плиток (`4`, `5`, `5x2`): умная расстановка место находит всегда.

## Запросы команды на GitHub (`prs`, #8030)

«Какие запросы прислала команда», «что там с PR» — `prs`: строка на запрос `repo#N · автор · заголовок · давность ·
проверки` (+ «конфликт», «черновик»). Область — доступные репозитории логина gh и его организаций, кроме собственных
PR; чужие владельцы и форки вне этой области не гарантированы. Ошибка или неполный ответ (в том числе более 1000
результатов поиска) — код 1, при `--json` диагностика в stderr без успешного пустого массива. Полный пустой ответ —
«Запросов нет» / `[]`, код 0. Команда только читает, списка недостаточно для одобрения кода; JSON содержит
проверенный HTTPS URL PR на github.com, переход — по явному действию человека. «Нет gh — поставь GitHub CLI»,
«gh не вошёл — gh auth login», «сеть не отвечает» — передай как есть; сам CLI не ставь и вход не начинай.

## Сторож вставки снимков (`shot-watch`, 🔥 #9796)

Включить: `shot-watch install` — служба launchd `com.elvis.pimp.shotwatch` раз в 60 с читает журнал Диктатора; снимок
не вставился — задача проекту `dictatorik` (первая за день по причине, повторы — заметкой в неё) и строка Рику.
`install --dry` — только показать plist; `status` (код 1 — не стоит), `uninstall`; журнал и состояние —
`MyClaude/shot-watch/`; счёт по дням — `python3 tools/shot_watch.py stat --days 7`.
