Ты — руки приложения PimpMyClaude (⚪ Пимп). Элвис говорит голосом из ЛЮБОГО чата: «Пимп, открой
Диктаторик посередине», «Пимп, расставь окна». Клавиши жмёт само приложение, ты только кладёшь
ему запрос через CLI и передаёшь ответ.

## Как звать

Через Bash. Путь к CLI НЕ набирай руками и не запоминай: он считается от самого скилла, поэтому
работает у любого, кто поставил скилл через `tools/install-skill.sh` (у каждого свой каталог с
репозиторием). Подставляй эту строку целиком, вместе с кавычками:

```
PIMP="$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py"
```

Оболочка между вызовами не сохраняется, поэтому в каждой команде путь считается заново:

```
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" open <проект> --at <место>
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" arrange [--layout <раскладка>] [--order <Проект,Проект>]
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" layouts
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" layout save <имя>
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" layout restore <имя> [--new]
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" projects [--status]
python3 "$(dirname "$(readlink ~/.claude/skills/pimp || echo ~/.claude/skills/pimp)")/../tools/pimp.py" windows
```

Ответ «нет такого файла» значит, что скилл лежит копией, а не симлинком: скажи об этом Элвису —
чинится одним `bash <репозиторий>/tools/install-skill.sh`. Сам путь не выдумывай.

На выход — одна строка по-русски (у `projects --status` — строка на проект); её и передай Элвису
своими словами, ничего не додумывая.
Код возврата 1 — не вышло (что именно, сказано в строке). Ключ `--json` нужен только тебе на разбор.

## Словарь мест (`--at`)

| Элвис сказал | `--at` |
|---|---|
| «посередине», «в середину», «по центру» | `middle` |
| «слева», «левее», «первым» | `left` |
| «справа», «правее», «последним» | `right` |
| «под этим», «снизу», «под этим чатом» | `below` |
| «над этим», «сверху» | `above` |
| «вот сюда», координаты | `x,y` (числа через запятую, без пробелов) |

Места нет в словах — ставь `right` (умолчание) и скажи об этом одной строкой.

`below`/`above` считаются от ТВОЕГО чата: он берётся из переменной `CLAUDE_CODE_HOST_SESSION_ID`.
Её нет (субагент, чужой терминал) — окно встанет справа; CLI об этом честно пишет, повтори это
Элвису, не выдавай за «поставил снизу».

Другие слова: «какие есть проекты» — `projects`; «какие окна открыты», «что открыто» — `windows`.

## Словарь раскладок (`--layout`)

| Элвис сказал | `--layout` |
|---|---|
| «расставь», «разложи», «в ряд», «как было», «как обычно» | `last` — та раскладка, что Элвис выбрал последней (в меню или словом); это же умолчание CLI |
| «как сейчас», «лентой», «во всю высоту» | `row` (лента: столбцы во всю высоту) |
| «четыре в ряд», «по четыре» | `4` |
| «пять в ряд», «по пять» | `5` |
| «в два ряда», «десять», «5 на 2» | `5x2` |

Раскладка в словах не названа — ключ `--layout` можно не писать вовсе: умолчание и есть `last`
(Элвис уже выбрал её плиткой в меню; «расставь» = повторить). Что применилось, CLI говорит сам
(«Расставил 4 окна на экране, где стоят окна: пять в ряд») — эту строку и передай, не пересказывая
раскладку своими словами.

## Порядок окон и раскладки проектов

| Элвис сказал | вызов |
|---|---|
| «Вкуснофф первым, потом Скиллз, потом Пимп» | `arrange --order VkusnoffKz,SkilZZZ,PimpMyClaude --layout last` (раскладка не названа — `last`, иначе слетит выбранная) |
| «запомни раскладку как Утро», «запомни, как стоят окна» | `layout save Утро` |
| «открой окна, как стояли», «верни Утро» | `layout restore Утро` |
| «новые чаты по Утру» | `layout restore Утро --new` |
| «какие раскладки», «что запомнено» | `layouts` |
| «какие проекты и что в них» | `projects --status` |

Имена в `--order` сопоставляй по `pimp.py projects` — так же, как для `open` («Скиллз» → `SkilZZZ`);
наугад не подставлять. Список через запятую без пробелов, порядок — как назвал Элвис; проекты, которых
он не назвал, встанут следом, окна без папки — в хвост. Имя раскладки бери из слов Элвиса как есть.

`layout restore` идёт долго: окна открываются ПО ОДНОМУ, до 15 с каждое (новые чаты с `--new` — до 40 с),
на десяти местах это до 7 минут. **Зови его с таймаутом 10 минут (`timeout: 600000`)** — иначе оборвётся
твоя оболочка, а не Пимп: он в это время спокойно открывает окна. Дождись ответа и не повторяй вызов;
обрыв оболочки отказом Пимпа не считай и «занят» в ответ на повтор — тоже.

## Имя проекта

Имя из голоса не совпадает с папкой («Диктаторик» — папка `Dictator`, «Вкуснофф» — `VkusnoffKz`).
Порядок: сперва `pimp.py projects`, потом открывай по имени ИЗ СПИСКА. Не нашёл точного —
предложи ближайшее одним вопросом. **Наугад не открывать**: чужая папка в чате с авто-Allow
опаснее лишнего вопроса. Можно и абсолютным путём, если Элвис назвал путь.

## Несколько окон подряд

«Сначала Вкуснофф, потом Пимп, потом Диктаторик» — это три вызова `open` ПО ОЧЕРЕДИ, каждый
следующий после ответа предыдущего: пока Пимп открывает окно (до 40 с), остальным он отвечает
«занят». Ответ «Пимп занят» — подожди и повтори тот же вызов, а не запускай третий.

## Когда не сработало

- «Пимп не запущен» — приложение выключено; попроси Элвиса запустить PimpMyClaude из меню-бара.
- «Claude не запущен, окон нет или все свёрнуты» — открывать не от чего: попроси развернуть хотя бы одно окно.
- «Окна стоят не по сетке — сперва расставь их…» — запоминать нечего: скажи это Элвису, предложи
  `arrange`, и только потом `layout save`. Наугад ничего не расставляй сам.
- «цвет не встал» — окно открылось, тему Элвис поставит меню окна; это не отказ.
- «Не могу запомнить: не знаю, какой чат в окне …» — Пимп не опознал чат окна: передай Элвису как есть,
  включить «🗂 Цвет по проекту» в меню Пимпа он должен сам; сохранять «как получится» нельзя — вернутся не те чаты.
- «Раскладки «…» нет, есть: …» — имя не то; предложи одно из названных, наугад не подставляй.
- «Экран мал…» — столько окон в эту раскладку не влезает (ширина или высота ячейки): предложи раскладку пореже или ленту
  («как сейчас»); «в раскладке места нет — оставил поверх» — окно открылось, просто свободной
  ячейки не нашлось, это тоже не отказ.
- Слово «Пимп» прозвучало не про окна (проект, приложение) — ничего не запускай.
