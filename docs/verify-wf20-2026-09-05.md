## Находки

**1. [важно] Битый `.pimpmyclaude.json` удаляется на «🧹 Всё как у Claude»**
`app/Sources/ClaudeAX/ProjectPaint.swift:326-327`. У битого файла `store.settings(in:)` → nil, значит `old` пуст; все слои `.reset` → `settings.isEmpty` → `store.remove(from: folder)` сносит файл вместе с чужими ключами. План 3.6 прямо говорит: «битый — файл не трогаем вовсе, плашка «битый, не трогаю»». Тест `testProjectWriteNoticeShowsOncePerFolder` проверяет только путь `.set`, путь сброса — нет.
Правка: перед `store.remove` отличить «файла нет» от «файл битый» и на битом выйти с той же плашкой:
```swift
guard !settings.isEmpty else {
    let raw = try? String(contentsOf: store.url(in: folder), encoding: .utf8)
    if raw != nil, ProjectSettings.merged(file: raw, settings: ProjectSettings()) == nil {
        notice(MenuModel.projectBroken(name), folder: path, broken: true); return
    }
    store.remove(from: folder)
    if let target = target(for: title) { repaint(target) }
    return
}
```

**2. [важно] Выбор темы в окне БЕЗ своей папки уезжает в проект главного окна**
`ProjectPaint.swift:315` через `folder(for:)` (`:383-386`, запасной вариант `index.mainWindow()?.folder`). Тик красит строго по `index.folder(forTitle:)` и такое окно не трогает, а запись — с запасным вариантом: попап обычного чата claude.ai (в индексе его нет) молча перепишет `.pimpmyclaude.json` папки главного окна и перекрасит все её окна. Это противоречит строке плана 3.6 «Окно без папки — проект молчит, выбор остаётся местным». Тест `testManualChoiceWithoutFolderWritesNothing` дыру не ловит: в стенде главного окна нет вовсе (`about:blank`).
Правка — строгий поиск папки в `noteManualChoice`, запасной вариант только для безымянного окна и заглушки:
```swift
guard enabled else { return }
let clean = title.trimmingCharacters(in: .whitespacesAndNewlines)
let found = clean.isEmpty || clean == ProjectPaint.mainWindowTitle
    ? index.mainWindow()?.folder : index.folder(forTitle: clean)
guard let folder = found else { return }
```
(`folder(for:)` при этом остаётся как есть — её берёт `target(for:)`.)

**3. [средне] Снятый слой не снимается с остальных окон проекта**
`ProjectPaint.swift:325`: `marks = marks.filter { $0.value.folder != path }` выбрасывает отпечатки целиком вместе со списком `layers`. Ближайший тик красит соседнее окно с `previous == nil`, а `layer(_:_:_:)` (`:285-288`) даёт `.reset` только по прошлым `layers`. Итог: в проекте были тема+шрифт, в окне A выбрали «Как у Claude» в «Шрифт ▸» — из файла шрифт ушёл, а на окне B он остался висеть. В WF15 такое забывание было осознанным («окна назад НЕ перекрашиваем»), в WF20 правило обратное.
Правка — гасить отпечаток, а не забывать его:
```swift
marks = marks.mapValues { $0.folder == path
    ? Mark(match: $0.match, title: $0.title, folder: $0.folder, digest: "", layers: $0.layers)
    : $0 }
```
(у известной папки `wanted` теперь никогда не nil, значит digest `""` гарантированно не совпадёт и тик отработает.)

**4. [мелко] Живые цвета, включённые при открытой панели, не доезжают никогда**

Сегодня почти недостижимо: при `editorOpen` меню от наведения не всплывает (`hoverPaused`), другого входа в живые цвета нет — но README обещает «поедет, как только панель закроют», и это неправда.
Правка: в `ThemeEditor.finish()` после `ClaudeActions.themeEditorTitle = nil` (`ThemeEditor.swift:144`) дописать `_ = actions.resendLiveColors()`.
