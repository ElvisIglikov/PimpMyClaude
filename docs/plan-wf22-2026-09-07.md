## Что делаем

### A. Разбор сводки в объекты (страница)
`statusBlocks(text)` → `[{number, state, about, steps:{done,total}|null, time, roles:[{role, agents, model, effort, running}]}]`
вместо строк; `statusLine` остаётся только для `status().statusFeed` (диагностика). Роль узнаётся по первому слову
(планирование/критика/кодинг/проверка), агенты — «я»/`N агент(а/ов)`, модель и эффорт — хвост; `running` — `💭` в
конце строки. Потолки прежние (24 проекта, 8 КБ на проект, 32 КБ всего).

### B. Живой этап и заливка (1A, 2A, #5543)
- Идущий сегмент: заливка = `шаги done/total` идущего воркфлоу (нет «шагов» — 1/4 за каждый этап с `running` или
  записанный этап), минимум 8 % чтобы был виден. Поверх — **мягкий пульс свечения** (box-shadow акцентом,
  2,4 с ease-in-out, `prefers-reduced-motion` → без пульса). Ждёт ✋ — жёлтый без пульса, упал 🛑 — красный без пульса.
- Вся полоса «готово» ✅ — зелёная (`#4dbb7d`) и тоже с мягким пульсом (готово = продолжать).
- Готовые воркфлоу — акцент темы, как сейчас; запланированные — пустые.

### C. Карточка сегмента (3A, #5566) — дизайн по макету v3
Клик по сегменту → карточка: `Workflow N · готов ✅ / идёт / ждёт / упал`, «о чём», время, четыре этапа строками
`план · критик · кодинг · проверка` с состоянием (✅ сделан, 💭 идёт, ⬜ не начат) и «кто» (`2 агента · Opus max`),
`шаги N из M`. Ширина = ширина окна − 12 px, переносы, потолок высоты 60 % окна с прокруткой; закрывается кликом
вне и Esc (Esc не глотаем, когда карточка открыта). Дизайн — **макет v3 карточки** (Fable xhigh, три варианта,
«(рекомендую)», подпись «сделал: макет · Fable 5.1 xhigh · дата» — правило #5570), буква Элвиса до кодинга C.
История запусков (#5566): карточка готового воркфлоу показывает то же самое — это и есть история; отдельного
журнала не заводим.

### D. Сводка не режется (Swift, старый план п. 1–3)
`StatusFeed` перед отправкой сжимает `status.md`: оставляет шапку (3 строки), заголовки Workflow и строки `- …`,
выкидывает пустые и «Сейчас/Ждёт»; переводы строк — как есть (экранирование не трогаем). Порядок проектов — по
`mtime` файла, свежие первыми (а не по алфавиту). Потолок 32 КБ остаётся. Контракт команды побайтно прежний.
