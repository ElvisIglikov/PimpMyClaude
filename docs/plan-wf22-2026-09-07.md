## Что делаем

### A. Разбор сводки в объекты (страница)
`statusBlocks(text)` → `[{number, state, about, steps:{done,total}|null, time, roles:[{role, agents, model, effort,
running}]}]`; номер — ЦЕПОЧКА клавиш (2️⃣9️⃣ → 29, 🔟 → 10, 4️⃣0️⃣ → 40). `statusLine` остаётся и отдаёт ТЕ ЖЕ строки знак в знак
(`status().statusFeed` и его поля не переименовывать — их читает гейт через probe). `statusFeedLines`: точное имя
первым, префикс — только когда он единственный (критик, важно 5). Потолки прежние (24 проекта, 8000 знаков, 32 КБ).

### B. Соединение сегмента со сводкой — по значку, не по номеру (критик, блокер 2)
- Идущий сегмент (по строке состояния) ↔ блок с 💭 в заголовке (несколько — последний по файлу).
- Готовый сегмент k из M ↔ k-й с хвоста среди блоков ✅ (история: последние готовые — они и есть воркфлоу этого чата);
  карточка показывает СВОЙ номер блока («Workflow 37 в проекте»), так что подмена не врёт.
- Будущий сегмент ↔ ⬜-блоки с головы после идущего; нет — карточка «запланирован, сводки нет».
- Проект в сводке не найден — карточка «сводки нет», как сегодня «Воркфлоу N · идёт».

### C. Живой этап и заливка (1A, 2A, #5543)
- Заливка идущего сегмента = **пройденные этапы из четырёх** (план → критик → кодинг → проверка; критик, важно 4):
  роли из блока — каждая = четверть; идущий этап (💭 или последний записанный) даёт половину своей четверти;
  ролей нет — `шаги N из M`; ничего нет — минимум 8 %, чтобы сегмент был виден.
- Пульс — **`element.animate()`** на отдельном слое свечения (opacity 0,35 → 0,8 → 0,35, 2,4 с, бесконечно), не
  box-shadow; отмена в `track()` и на `dispose()`; стоп при `document.hidden`; `prefers-reduced-motion` — без пульса
  (критик, важно 1). Никаких новых `CSSStyleSheet`/`<style>`.
- Вся полоса «готово» ✅ — зелёная (`#4dbb7d`) с тем же пульсом. Ждёт ✋ — жёлтый без пульса; упал 🛑 — красный без пульса.
- Новый чат без строки состояния — один пустой контур (PROGRESS.md п. 1).

### D. Карточка сегмента (3A, #5566) — дизайн по букве Элвиса на `mockup-wf22-cards.html`
Клик по сегменту → карточка (по выбранному варианту 3A/3B/3C): `Workflow N · готов ✅ / идёт / ждёт / упал`, «о чём»,

Ширина = ширина окна − 12 px, переносы; **прокрутки нет** — потолок 60 % высоты окна, лишнее режется троеточием
(критик, важно 2); `pointer-events:none` остаётся, попадание в карточку — проверкой её прямоугольника в `onProgressDown`
до `progressTipClose` и в `onProgressMove`; обычный `div` с `aria-hidden`, без `role`/`data-state` (важно 3); Escape —
существующий слушатель. История (#5566) = карточка готового сегмента (правило B), отдельного журнала нет.

### E. Сводка доезжает целиком (Swift; критик, блокер 1)
`StatusFeed`: блок Workflow **сжимается** перед отправкой — заголовок, «о чём», «шаги», время, роли; пустые и
«Сейчас/Ждёт» выкидываются, шапка (3 строки) остаётся; и **режется с НАЧАЛА файла** — хвост (живое) важнее головы;
`limit` = 6 КБ байт остаётся числом в плане и в тесте: файл на 40 блоков → идущий блок доезжает. Порядок проектов —
по `mtime` (свежие первыми), `digest` считать по копии, отсортированной по имени (мелочь критика). Потолок 32 КБ
остаётся. Контракт команды побайтно прежний.

   номером, честно.
3. Пульс в пяти окнах — opacity-анимация дешёвая, стоп в скрытых окнах.
4. Буква по карточке задержит только D; A, B, C, E кодятся сразу с временной карточкой варианта «(рекомендую)» 3A.
