### Часть B — «Обкэшить» из попапа рождает новое окно (#5575, #5535 для `cashout`)

**B1 Swift.** Развилка — чистая функция `ClaudeActions.cashoutRoute(title:isMainTitle:knownChat:) -> CashoutRoute`
(`.main` | `.popout(chat: String?)`), тестируется без окон (критик, важно 3). «Главное» — по резолверу
`isMainWindowTitle: (String) -> Bool` = `ProjectPaint.windowKey(forTitle:) == mainKey` (критик, блокер 3), новое
сиденье-замыкание в `ClaudeActions` по образцу `chatName`/`projectView`, проводка в `ClaudeAXController` рядом с
`:93-95`; там же два сиденья `chatForTitle: (String) -> String?` (из карты probe через `ProjectPaint`) и
`projectForChat: (String) -> Project?` (папка чата из индекса → `Project(folder:name:lastFocusedAt:)`);
прямой зависимости `ClaudeActions` от `ProjectIndex`/`ChatProbe` — нет (критик, важно 4).
- **Главное окно — как сегодня по смыслу, адрес точнее**: команда `cashout` полями `scope:"window", title, match`
  (`match = mainWindowMatch()`; на домашнем экране пути нет → `scope, title`), затем ⌘N в него; вставка на
  домашнем экране прежняя.
- **Попап**: фокус → `cashout` полями `scope:"window", title, chat?` (`chat` — только если страница сама назвала
  свой id в карте probe; иначе заголовком, как сегодня, — риск двух окон с одним именем назван ниже; `match`
  попапу не шлётся никогда) → через `cashoutNewChatDelay` вместо `newChat(popout)` — **`newWindow(popout,
  project: projectForChat(chat), origin: popoutOrigin(near: рамка попапа), transfer: true)`**: тот же путь, что
  «▸ проект» (имя `chatName(project)`, слои проекта и авто-цвет, запись в `projects.json`); проекта нет —
  «Здесь же» с `transfer: true`. Хоткей ⇧⌘N при попапе в фокусе идёт той же веткой.
- **Контракт `new-window` расширяется одним полем** (критик, блокер 2): необязательное `transfer: true` **после
  `name`, перед слоями**; порядок побайтно `scope, title, match?, x, y, text, folder, name, transfer?, [theme],
  [font], [size], [frame]`. Ставит его ТОЛЬКО ветка «Обкэшить»; ⌥⌘N, «▸ проект», «Здесь же» и канал «Пимп»
  (`newWindow(in:on:)`) поля не пишут никогда — тест на это в оба батча.
- Порядок полей `cashout` побайтно: главное окно `scope, title, match?`; попап `scope, title, chat?`.

### Часть C — цвет за папкой сразу на домашнем экране (#5576)

**C1 Страница.** Ответ `chats()` получает поле `folder` (string | null) **после `store`, перед `themes`** —
только у главного окна **и только на домашнем экране** (`isMainWindow() && newWindowAtHome()`; критик, блокер 4):
`newWindowFolderNow(newWindowFolderStore)`, когда стор папки уже найден; не найден — один раз запускаем
`newWindowFindFolderStore(newWindowToken)` в фоне (промис `chatsFolderScanInFlight`, второй не заводим) и
отвечаем `null`; срыв скана — `null`, следующий круг. В открытом чате, у попапов и чужих страниц — `null`.
То же поле в `status().chat.folder`.
**C2 Swift.** `ChatPage` получает `path: String = ""` и `folder: String? = nil` (значения по умолчанию — 8
конструкторов в тестах не трогаются; критик, мелочь 1); `parseAnswer` принимает `folder` только у `kind == .main`,
абсолютный путь ≤ 1024 знаков. `ProjectPaint.targets()`: **папка из ответа берётся ТОЛЬКО когда
`index.mainWindow() == nil`** (домашний экран) и свежий (`isRecent`) ответ главного окна имеет `path ==
"/epitaxy"` и `folder` → цель `key: main, match: "/epitaxy", folder: root(folder)` (подъём к корню
`ProjectFolder.root(for:…)`, новый `index.root(of: URL)`: чип может показывать подпапку). В открытом чате —
поведение побайтно прежнее (сессия → `cwd`), `writableFolder(for:)` не трогаем (на домашнем экране ручной выбор,
как и сегодня, файла проекта не пишет). **Ожидаемое поведение, названное заранее** (критик, мелочь 3): цвет
домашнего экрана ложится в ключ `main` на странице и в `window-themes.json`, поэтому после перезапуска Claude
домашний экран вернётся в цвете последнего проекта.
**C3 Частота.** `ChatProbe.askInterval` 15 с остаётся; новый `homeInterval = 4` с (на общем тике 2 с меньше не
выйдет) действует **только пока последний свежий ответ главного окна говорит «путь = /epitaxy»** — не «Claude
впереди» (критик, важно 5): `tick(...)` получает признак из своей же карты, без нового параметра контроллера.
Цена — круг probe раз в 4 с ровно на время домашнего экрана. **Факт для гейта, не для кода**: меняется ли `cwd`
в `local_*.json` при «Change directory» (одна проверка на диске Элвиса) — от этого зависит, чинит ли WF29
открытый чат живьём; нет — задача-продолжение #5448.
**Диагностика:** `statusText` `project=…` дополняется папкой из ответа: `on/<папка>/<painted>/<known>/home:<имя|—>`.
