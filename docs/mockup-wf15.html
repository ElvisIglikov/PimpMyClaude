Вопросы Элвису

1. Где хранить
  • (рекомендую) файл .pimpmyclaude.json в папке проекта — настройки едут с папкой
  • только строка в AGENTS.md проекта (короче, но приложение правит твой файл)
  • общий список внутри приложения (в папки не пишем совсем)
2. Строку в AGENTS.md писать?
  • (рекомендую) да, но отдельным пунктом меню и по клику — как памятку агенту, не как хранилище
  • не трогать AGENTS.md вообще
3. Место в меню
  • (рекомендую) внутри «🎨 Оформление ▸» первым разделом — это про вид
  • отдельным пунктом верхнего уровня (вариант Б)
4. Когда настроек нет
  • (рекомендую) подсказка один раз на папку, дальше молчим
  • окошко с кнопкой «Записать»
  • ничего не показывать, только пункт меню
5. Главное окно красить?
  • (рекомендую) да — для этого в страницу добавится три строчки; переустанавливать ничего не надо, ни тебе, ни команде
  • страницу не трогать вовсе: тогда цвет получают только вынесенные окна чатов, а главное окно остаётся как есть (в меню так и будет написано)

Как приложение узнаёт папку: у каждого чата Claude Code на диске лежит запись с путём папки и заголовком, а какой чат сейчас открыт — видно по адресу страницы. Патч Claude и лоадер не меняются, поэтому переустанавливать («Поставить снова») ни тебе, ни команде не придётся; в саму страницу добавятся три строчки — без них главное окно по имени не отличить от безымянных окошек, и цвет разлился бы на все сразу (вопрос 5). Ручной выбор сильнее проекта: выбрал окну цвет руками или раскрасил «по кругу» — по проекту оно больше не перекрасится, пока не сменишь чат. Открыто меню — фоновая покраска ждёт и примерку не сбивает. Перешёл в проект без настроек — окно возвращается к прежнему виду, чужой цвет не залипает. Если Claude Code запущен из подпапки, настройки всё равно берутся из корня проекта. Тумблер «Красить чаты по проекту» выключает всё разом и возвращает окна к прежнему виду.
