## Находки

### 1. [средне] Смена чата в главном окне: цвет поедет не за 4 с, а через круг probe

`ProjectPaint.swift:238` берёт ответ страницы про главное окно, пока ему меньше 60 с
(`ChatProbe.mainChatSeconds`, `ChatProbe.swift:92`), и этот ответ ПЕРЕБИВАЕТ свежий `status.json`.
Лоадер переписывает `status.json` раз в 2 с (`patch-claude.mjs:191`), а карта probe обновляется не чаще
раза в 15 с. Значит после переключения чата в главном окне цвет держится старым, пока не приедет новый
круг: обычно 6–8 с, в худшем ~17–19 с.

Гейт п. 7 плана ждёт «за 4 с главное окно перекрашивается» — это ожидание не сбудется.
Правка: либо поправить ожидание гейта, либо опустить `ChatProbe.mainChatSeconds` (одна константа,
`ChatProbe.swift:92`) до ~10 с. Конечное состояние верное в обоих случаях, речь только о задержке.

### 2. [средне] Главное окно: чат, которого нет в индексе, откатывается к `status.json`

`ProjectPaint.swift:246`:

```swift
folder: session.map(index.folder(of:)) ?? main.folder
```

Страница назвала чат, а `index.session(for:)` его не знает → `session == nil` → берётся `main.folder`,
то есть папка чата из `status.json`. Это ровно то, что запрещает комментарий тремя строками выше
(`:239-241`) и что отчёт батча B числит среди отступлений («к чату из `status.json` НЕ откатываемся»).
Проверено отдельно: `Optional.map(...) ?? fallback` при `nil` даёт fallback.

Живой вред узкий (окно расхождения ≈ 2 с, и чаще откат даёт как раз верный ответ), но правило
#5455 в коде не записано, а отчёт утверждает обратное. Правка в одну строку:

```swift
folder: named == nil ? main.folder : named.flatMap { index.session(for: $0) }.map(index.folder(of:))
```

Тестом это не закрыто: `testMainChatPrefersPageAnswer` (`ProjectTests.swift:1473`) гоняет только случай
«чат страницы есть в индексе».

### 3. [мелко] Находка 5 WF20 закрыта только для цели `main`

`paintableTitles()` отдаёт заголовки ВСЕХ окон на экране, включая главное
(`ClaudeActions.swift:714-730`), поэтому главное окно даёт две цели: `main` и `w:<настоящий заголовок>`
(`ProjectPaint.swift:264-272`). Новая сверка владения примеркой идёт КЛЮЧОМ
(`ProjectPaint.ownedByEditor`, `:336-339`) и защищает только `main`; дубль `w:` раньше защищался
заголовком, теперь не защищён ничем — при смене вида проекта с открытой панелью «Своя тема» тик может
погасить примерку через него.

Правка одной строкой, старые тесты от неё не краснеют:

```swift
if let key = ClaudeActions.themeEditorKey { return key == target.key || ClaudeActions.themeEditorTitle == target.title }
```

### 4. [мелко] Ничья заголовков считается не совсем ничьёй

`ChatProbe.chat(forTitle:)` (`ChatProbe.swift:166-177`) пропускает страницы с `chat == nil`
(`guard let chat = page.chat else { continue }`). Два попапа с ОДНИМ заголовком, где id назвал только
один, отдают этот id — и ручной выбор темы в неопознанном окне уедет в чужой проект
(`ProjectPaint.writableFolder`, `:499`). План (тест 19) требует на ничью `nil`. Тест 19
(`ChatProbeTests.swift:293`) закрывает только случай «оба назвали id».
