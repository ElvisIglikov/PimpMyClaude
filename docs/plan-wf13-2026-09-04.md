## Что выяснено (разведка 04.09 17:30–17:50 + разбор критика; в код агенту не лезть заново)

- Окна «Open in new window» — это **popout**: страница claude.ai держит Zustand-стор с `popoutWindows: Map` и действием
  `openPopout(entry)`. Стор экспортируется из чанка `shared-2-<hash>.js` (сейчас экспорт `ml`), чанки лежат на
  `https://assets-proxy.anthropic.com/claude-ai/v2/assets/v1/` и перечислены в `<link rel="modulepreload">` главного окна.
  **Найти стор надо поведенчески**, а не по имени: `for (const u of [...document.querySelectorAll('link[rel="modulepreload"]')]
  .map(l => l.href)) { const m = await import(u); for (const k of Object.keys(m)) { const v = m[k]; if (typeof v === "function"
  && typeof v.getState === "function" && v.getState().popoutWindows instanceof Map && typeof v.getState().openPopout ===
  "function") → стор } }` — проверено живьём 04.09 17:43, 43 модуля, находится за ~1 с; кэшировать в замыкании раздела.
  Динамический `import()` того же URL возвращает уже загруженный экземпляр модуля (одна карта модулей документа).
  **Важно (критик п. 12):** `import()` ИСПОЛНИТ те модули, которые страница ещё не выполняла (`modulepreload` ≠ исполнение) —
  это чужая инициализация в чужой странице, поэтому искать только по приходу команды и останавливаться на первом совпадении.
- Запись открытого окна (снято живьём): `{type:"code-session", sessionId:"local_<uuid>", sessionType:"local", isSsh:false,
  title:"Привет", entryPoint:"drag_tear_off", initialPosition:{x:586,y:303}}`. `initialPosition` — экранные точки.
  Сама страница вызывает то же с `entryPoint:"context_menu"` (пункт «Open in new window») и `"cmd_click"` (⌘-клик по строке
  чата в сайдбаре). `closePopout(id)` закрывает.
- **Popout несуществующей сессии показывает «This session couldn't be found»** (проверено: свежий `local_<uuid>` → пустое
  окно с кнопкой «Start a new session», которая переводит ГЛАВНОЕ окно на /epitaxy и закрывает popout). Локальная
  сессия рождается только при ПЕРВОМ сообщении (композер: `sessionId ?? "local_" + crypto.randomUUID()` → spawn).
  Значит одной кнопкой чистый пустой чат в окне не открыть — только чат с первым сообщением. Элвис руками делает то же
  самое: «нажимаю нью, говорю ему “Привет”, потом тяну чат из сайдбара в пустое место».
- Композер Claude Code: `[data-testid="code-prompt-input"]` (ProseMirror, contenteditable), кнопка отправки
  `[data-testid="code-prompt-send"]` (бывает `disabled`, пока не выбраны папка/модель). Вставка текста — уже есть
  `insertIntoEditor` (inject.js:3068), пустоту поля меряет `editorText` (inject.js:3003) — тем же способом «Обкэшить»
  отказывается затирать черновик («в поле черновик», inject.js:3097).
  Новый чат в главном окне: `/epitaxy` (домашний экран «What's up next», папка — последняя использованная). После отправки
  адрес становится `/epitaxy/local_<id>` (pending-nav), строка чата в сайдбаре `[data-row-key]` появляется, когда сессия
  реально создана — по ней Элвис и тянет окно.
- **История роутера (поправлено критиком, п. 4).** После ⌘N и отправки главное окно проходит ДВЕ навигации:
  `prev` → `/epitaxy` → `/epitaxy/local_<id>`. Значит один `history.back()` вернёт на `/epitaxy`, а не на прежний чат:
  назад нужно ДВА шага (`history.go(-(history.length - lengthBefore))`) либо — надёжнее — клик по строке сайдбара
  прежнего чата `[data-row-key$="<prevId>"]` (это собственная навигация приложения). `history.pushState({}, "", "/epitaxy")`
  затирает служебный `history.state` роутера и ломает back/forward до перезагрузки страницы — держим только как последний
  запасной путь для ухода на `/epitaxy`, для возврата не используем вовсе.
- Строки сайдбара: `[data-testid="sidebar-recents"] [data-row-key="…"]`, ключи вида `chat:<uuid>` / `code:…`/`local_…` —
  искать по `[data-row-key$="<id>"]`.
- Главное окно — страница `https://claude.ai/…` (`isMainWindow()`, inject.js:763); popout — `about:blank`. Но «такая
  страница одна» — **допущение, живьём не проверенное** (критик п. 9): окажется два окна claude.ai — оба выполнят команду
  и создадут по чату. Поэтому одного `isMainWindow()` мало: команда адресуется заголовком, страница требует
  `isMainWindow() && addressed(detail)` (inject.js:1210) — ровно как `workflow` и `cashout`.
  На странице есть `window.electronWindowControl.focus()` (мост Claude) — запасной способ поднять главное окно.
- **`scope` страница сверяет только с `"all"`** (раздел 2а inject.js); значения `"main"` она не знает — это был бы третий,
  мёртвый вариант контракта. Наш scope — `"window"` (`MenuModel.themeScopeWindow`), отбор главного окна остаётся странице.
- **Запись команды.** `CommandChannel.write(action:extra:)` (CommandChannel.swift:190) сортирует ключи по алфавиту и делает
  ВСЕ значения строками. Порядок полей и числа даёт только `write(action:fields:)` + `payload(action:fields:)` с
  `CommandValue` (`.number(Int)` заведён в WF12 как раз под кегль). Образец — `ClaudeActions.workflowFields` (ClaudeActions.swift:153).
- **Перепатча у команды не будет**: лоадер (`patch-claude.mjs:203`, `Loader.swift:79`) рассылает `command.json` во все страницы
  без белого списка `action` — новая команда доедет как есть, «Поставить снова» никому не нужно.

## 0. Микро-разведка на гейте до батчей (оркестратор, ~10 минут, probe.js, мышью не водим)

Три неизвестных, без которых батчи пишут по догадке (критик п. 7). Скрипт кладём в
`~/Library/Application Support/MyClaude/probe.js` (лоадер выполняет его во всех страницах при изменении файла, раз в 2 с),
ответ читаем из `~/Library/Application Support/MyClaude/probe-result.json`. **Ответы вписать прямо сюда, в этот раздел,
до запуска волны.**

**П1. Что делает главное окно, когда `openPopout` забирает его собственную сессию?** (Может увести себя само — и это
подерётся с шагом возврата.) Открыть в главном окне любой существующий чат Claude Code (`/epitaxy/local_…`) и положить:

```js
(async () => {
  if (!location.href.includes("claude.ai")) return { skip: location.href };
  const findStore = async () => {
    for (const u of [...document.querySelectorAll('link[rel="modulepreload"]')].map(l => l.href)) {
      try {
        const m = await import(u);
        for (const k of Object.keys(m)) {
          const v = m[k];
          if (typeof v === "function" && typeof v.getState === "function") {
            const s = v.getState();
            if (s && s.popoutWindows instanceof Map && typeof s.openPopout === "function") return v;
          }
        }
      } catch {}
    }
    return null;
  };
  const store = await findStore();
  if (!store) return { store: false };
  const id = location.pathname.split("/").pop() || "";
  if (!id.startsWith("local_")) return { skip: "нужен открытый /epitaxy/local_…", path: location.pathname };
  const before = { path: location.pathname, title: document.title, popouts: store.getState().popoutWindows.size };
  store.getState().openPopout({ type: "code-session", sessionId: id, sessionType: "local", isSsh: false,
    title: document.title, entryPoint: "context_menu", initialPosition: { x: 200, y: 200 } });
  await new Promise(r => setTimeout(r, 2000));
  return { before, after: { path: location.pathname, title: document.title,
    popouts: store.getState().popoutWindows.size } };
})()
```

Ответ: `before.path === after.path` → главное окно остаётся на чате, шаг возврата нужен как задумано; путь сменился →
приложение уводит окно само, и шаг возврата упрощается до «проверить, куда увело».

**П2. Переживает ли черновик поля ввода ⌘N и возврат?** Элвис (или оркестратор) пишет в поле ввода текущего чата пару слов,
кладёт probe-снимок, затем жмёт **штатный ⌘N** (клавиша Claude, окно в фокусе) и кладёт probe-снимок ещё раз:

```js
(() => {
  if (!location.href.includes("claude.ai")) return { skip: location.href };
  const ed = document.querySelector('[data-testid="code-prompt-input"]');
  const rows = [...document.querySelectorAll('[data-testid="sidebar-recents"] [data-row-key]')]
    .slice(0, 5).map(n => n.getAttribute("data-row-key"));
  const was = window.__mcProbe || null;
  window.__mcProbe = { path: location.pathname, draft: (ed?.innerText || "").trim(), rows };
  return { was, now: window.__mcProbe, sendDisabled:
    document.querySelector('[data-testid="code-prompt-send"]')?.hasAttribute("disabled") ?? null };
})()
```

Ответ: `now.path === "/epitaxy"` и композер на месте → ⌘N даёт ровно тот экран, синтетический ⌘N не нужен;
`was.draft` вернётся в П3 → черновик по сессии живёт, риск снят.

**П3. Работает ли возврат кликом по строке сайдбара?** Сразу после П2 (не трогая окно) положить:


Ответ: `clicked:true` и `path` вернулся к `was.path` → возврат по строке сайдбара рабочий (основной путь шага 8);

## Решение

1. **Контракт команды** (страница и Swift побайтно, порядок полей после `id, action, at` — как в списке):
   `{"id","action":"new-window","at","scope":"window","title":<AX-заголовок окна>,"x":<число>,"y":<число>,"text":"Привет"}`.
   - Swift пишет ТОЛЬКО через `ClaudeActions.newWindowFields(title:x:y:text:)` + `commands.write(action:"new-window", fields:)`
     (как `workflowFields`); `x`/`y` — `CommandValue.number(Int)`. `write(action:extra:)` не использовать: он сортирует ключи
     и делает всё строками (критик п. 1).
   - `x,y` — **Quartz-точки** из `AX.frame(window).origin` + 40/40 (начало — левый верхний угол главного экрана, y вниз;
     это те же координаты, что у Electron), обрезанные по `Screens.mainUsableFrame` так, чтобы окно ~900×700 влезло целиком;
     окна под кнопкой нет — 120/120. NSScreen/AppKit-координаты (снизу вверх) не брать: окно уедет за экран.
   - `text` — первое сообщение, по умолчанию «Привет» (константа `MenuModel.newWindowText`; пустая строка недопустима —
     без сообщения сессии нет). В константе — **только приветствие**: никаких команд, путей и просьб что-то запустить
     (в этой сессии работает авто-Allow).
   - Страница проверяет `Number.isFinite(detail.x)`/`(detail.y)`, `scope === "window"`, непустой `text`.
2. **Страница (inject.js, новый раздел 12б «Новое окно»)**, исполняет только главное окно и только адресованное:
   `isMainWindow() && addressed(detail)`.
   1. Найти стор popout — **только по приходу команды** (не при инжекте), первое совпадение, каждый `import` в своём
      `try/catch`, результат в кэш замыкания; кэш перепроверять, если у стора пропала `popoutWindows`. Второй источник
      адресов, если `modulepreload` пуст: `performance.getEntriesByType("resource")` по `/assets/v1/*.js`.
      Нет стора — `state.newWindow = {state:"no-store"}`, плашка (см. 2.9), дальше не идти.
   2. Запомнить `prev = location.pathname`, `prevId` (последний сегмент пути), `lengthBefore = history.length`.
   3. Новый чат открывает **Swift штатным ⌘N** (тот же проверенный путь, что `ClaudeActions.newChat`, ClaudeActions.swift:457:
      фокус окна + `app.postKey`), страница только ЖДЁТ (≤ 5 с, опрос 100 мс) `location.pathname === "/epitaxy"` и
      `[data-testid="code-prompt-input"]`. Синтетического `KeyboardEvent` нет. Не дождались — последний запасной путь
      `history.pushState({}, "", "/epitaxy") + popstate` с пометкой `pushed:true` в статусе (портит `history.state` роутера).
   4. **Проверка, что композер пуст** (иначе «Привет» приклеится к недописанной мысли Элвиса и уедет в модель):
      (а) `location.pathname === "/epitaxy"`; (б) редактор взят как `document.querySelector('[data-testid="code-prompt-input"]')`,
      а НЕ из `state.editor`/`findEditor()` (там кэш узла прошлого чата); (в) `editorText(editor) === ""`.
      Хоть одно не сошлось — **стоп**: не вставлять и не отправлять, статус `draft`, плашка, вернуть окно на `prev` (шаг 8).
   5. `window.focus()`, `electronWindowControl?.focus?.()`, `insertIntoEditor(editor, text, false)`.
   6. Отправка: дождаться `[data-testid="code-prompt-send"]:not([disabled])` до 3 с → клик; кнопка так и не ожила —
      `keydown Enter` на редакторе; адрес не сменился — статус `no-send` (а если видно, что не выбрана папка — `no-folder`)
      и плашка.
   7. Ждать (≤ 15 с) `location.pathname` вида `/epitaxy/local_…` → `id`; затем ждать (≤ 20 с) строку
      `[data-row-key$="${id}"]` в сайдбаре (нет строки — 1,5 с после смены адреса и дальше).
      `openPopout({type:"code-session", sessionId:id, sessionType:"local", isSsh:false, title:<заголовок из строки сайдбара
      или `document.title`>, entryPoint:"context_menu", initialPosition:{x,y}})` — **константу «Новый чат» не передавать**:
      это заглушка из `THEME_TITLE_STUBS`, у окна не будет ключа темы `chat:` вовсе.
   8. Вернуть главное окно: `prevId` есть → клик по `[data-testid="sidebar-recents"] [data-row-key$="<prevId>"]`;
      строки нет → `history.go(-(history.length - lengthBefore))` (это два шага, не один); не вернулось за 1 с — оставить
      как есть и записать `back-failed`. `pushState(prev)` для возврата не использовать (сломает роутер главного окна).
   9. **Видимая плашка при отказе** (молчаливый отказ запрещён — прецедент `MenuModel.workflowKitMissingAlert`):
      на `no-store`/`draft`/`no-send`/`no-folder`/`error` страница рисует свою короткую плашку на 3 с стилем подсказки
