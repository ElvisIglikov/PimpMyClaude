## Что выяснено (разведка 04.09 17:30–17:50, в код агенту не лезть заново)

- Окна «Open in new window» — это **popout**: страница claude.ai держит Zustand-стор с `popoutWindows: Map` и действием
  `openPopout(entry)`. Стор экспортируется из чанка `shared-2-<hash>.js` (сейчас экспорт `ml`), чанки лежат на
  `https://assets-proxy.anthropic.com/claude-ai/v2/assets/v1/` и перечислены в `<link rel="modulepreload">` главного окна.
  **Найти стор надо поведенчески**, а не по имени: `for (const u of [...document.querySelectorAll('link[rel="modulepreload"]')]
  .map(l => l.href)) { const m = await import(u); for (const k of Object.keys(m)) { const v = m[k]; if (typeof v === "function"
  && typeof v.getState === "function" && v.getState().popoutWindows instanceof Map && typeof v.getState().openPopout ===
  "function") → стор } }` — проверено живьём 04.09 17:43, 43 модуля, находится за ~1 с; кэшировать в замыкании раздела.
  Динамический `import()` того же URL возвращает уже загруженный экземпляр модуля (одна карта модулей документа).
- Запись открытого окна (снято живьём): `{type:"code-session", sessionId:"local_<uuid>", sessionType:"local", isSsh:false,
  title:"Привет", entryPoint:"drag_tear_off", initialPosition:{x:586,y:303}}`. `initialPosition` — экранные точки.
  Сама страница вызывает то же с `entryPoint:"context_menu"` (пункт «Open in new window») и `"cmd_click"` (⌘-клик по строке
  чата в сайдбаре). `closePopout(id)` закрывает.
- **Popout несуществующей сессии показывает «This session couldn't be found»** (проверено: свежий `local_<uuid>` → пустое
  окно с кнопкой «Start a new session», которая переводит ГЛАВНОЕ окно на /epitaxy и закрывает popout). Локальная
  сессия рождается только при ПЕРВОМ сообщении (композер: `sessionId ?? "local_" + crypto.randomUUID()` → spawn).
  Значит одной кнопкой чистый пустой чат в окне не открыть — только чат с первым сообщением. Элвис руками делает то же
  самое: «нажимаю нью, говорю ему “Привет”, потом тяну чат из сайдбара в пустое место».
- Композер Claude Code: `[data-testid="code-prompt-input"]` (ProseMirror, contenteditable), кнопка отправки
  `[data-testid="code-prompt-send"]`. Вставка текста — уже есть `insertIntoEditor` (раздел 12а inject.js, execCommand → paste).
  Новый чат в главном окне: `/epitaxy` (домашний экран «What's up next», папка — последняя использованная). После отправки
  адрес становится `/epitaxy/local_<id>` (pending-nav), строка чата в сайдбаре `[data-row-key]` появляется, когда сессия
  реально создана — по ней Элвис и тянет окно.
- Строки сайдбара: `[data-testid="sidebar-recents"] [data-row-key="…"]`, ключи вида `chat:<uuid>` / `code:…`/`local_…` —
  искать по `[data-row-key$="<id>"]`.
- Главное окно — единственная страница `https://claude.ai/…` (`isMainWindow()` в inject.js); popout — `about:blank`.
  На странице есть `window.electronWindowControl.focus()` (мост Claude) — запасной способ поднять главное окно.

## Решение

1. **Контракт команды** (страница и Swift побайтно): `{"id","action":"new-window","at","scope":"main","x":<px>,"y":<px>,
   "text":"Привет"}`. `x,y` — экранная точка левого верхнего угла нового окна (Swift: окно, с кнопки которого кликнули,
   +40/+40; нет окна — 120/120). `text` — первое сообщение, по умолчанию «Привет» (константа в Swift `MenuModel.newWindowText`;
   пустая строка недопустима — без сообщения сессии нет).
2. **Страница (inject.js, новый раздел 12б «Новое окно»)**, исполняет ТОЛЬКО главное окно:
   1. найти стор popout (см. выше; нет — `status().newWindow = {state:"no-store"}`, HUD-ошибка через `probe`-совместимый
      статус, дальше не идти);
   2. запомнить `prev = location.pathname`;
   3. перейти на домашний экран нового чата: `history.pushState({}, "", "/epitaxy"); dispatchEvent(new PopStateEvent("popstate"))`;
      ждать (≤ 5 с, опрос 100 мс) `location.pathname === "/epitaxy"` и `[data-testid="code-prompt-input"]`; не сработало —
      запасной путь: синтетический ⌘N (`document.dispatchEvent(new KeyboardEvent("keydown", {key:"n", code:"KeyN",
      metaKey:true, bubbles:true, cancelable:true}))`), снова ждать;
   4. `window.focus()`, `electronWindowControl?.focus?.()`, `insertIntoEditor(editor, text, false)`; отправить — клик по
      `[data-testid="code-prompt-send"]`, если кнопки нет — `keydown Enter` на редакторе;
   5. ждать (≤ 15 с) `location.pathname` вида `/epitaxy/local_…` → `id`; затем ждать (≤ 20 с) строку
      `[data-row-key$="${id}"]` в сайдбаре (или, если сайдбар свёрнут, просто 1,5 с после смены адреса);
   6. `openPopout({type:"code-session", sessionId:id, sessionType:"local", isSsh:false, title:"Новый чат",
      entryPoint:"context_menu", initialPosition:{x,y}})`;
   7. вернуть главное окно: если `location.pathname !== prev` → `history.back()`; через 1 с проверить, не вернулось —
      `pushState(prev)+popstate`;
   8. `status().newWindow = {state:"done"|"error", id, step, at}` на каждом шаге (это и есть гейт без клика). Всё через
      `track()`/`dispose` как остальные разделы; таймауты — `setTimeout`, снимаемые в dispose.
   Ограничения: команду выполнять по одной (второй клик во время работы — игнор со статусом `busy`); ошибка на любом
   шаге — вернуть главное окно на `prev` (шаг 7) и записать `error`.
3. **Swift**: `ClaudeCommand.newWindow`, пункт «🪟 Новое окно» в `MenuModel.entries` сразу после «💬 Новый чат», клавиша
   ⌥⌘N (Carbon-хоткей регистрируем; у Claude ⌥⌘N не занята — меню File/View/Window сняты 04.09 17:35). `ClaudeActions`:
   `app.activate` + фокус окна под кнопкой (как `cashout`), затем `commands.write(action:"new-window", extra:[x,y,text])`
   (порядок полей — как в контракте). HUD «Открываю новое окно…» (2 с). Разделители не трогать (после «Новый чат» —
   как был). README (список пунктов, раздел «Меню»), TEAM.md (одна строка), тест `testMenuKeysMatchReadme` и соседние —
   обновить ожидания; новый тест: порядок полей команды `new-window`.
4. Порядок команд в `runCommand` страницы: `new-window` рядом с `workflow` (раздел 16 подписки), `addressed` не нужен —
   фильтр `isMainWindow()`.
5. **Не делаем**: выбор папки (берётся последняя, как у Элвиса руками), тема нового окна (это «Автопокраска»/WF14),
   настройка текста первого сообщения в меню.
