## Решения

1. **Полоска v2** (#5324). Место — ровно нижняя кромка рамки поля ввода (`.epitaxy-prompt` или его рамочный
   потомок с border/box-shadow: `getBoundingClientRect().bottom`), не строка инструментов. Сегменты: M штук по
   числу воркфлоу из строки «WF N из M», зазор 3 px, скругление; готовые (< N) — полные, текущий — доля P %,
   будущие — пустой контур 1 px с прозрачностью 0.25; ✅ → все полные; 🛑 → текущий красный; ✋ → текущий жёлтый;
   без «WF» (одиночный) — один сегмент. Цвет — акцент темы (как сейчас). Зона наведения 10 px над линией
   (`position:fixed`, как у донора) → своя подсказка (div, не `title`): заголовок «Воркфлоу N из M · P %» и по
   строке на воркфлоу из сводки проекта, если она пришла (см. п. 2), иначе только заголовок.
2. **Сводка для подсказки** — файл status.md проекта. Страница файлов не читает; приложение шлёт их само:
   `StatusFeed` в Swift раз в 60 с (и при показе меню) читает `<projectsRoot>/*/{docs,audit,work}/status.md`
   (`projectsRoot` из `claude.json`, по умолчанию `~/_ElvisProjects`; папки нет — ничего не шлёт) и при смене
   содержимого пишет команду `{"id","action":"status","at","scope":"all","projects":[{"name":"PimpMyClaude","text":"…"}]}`
   (text — сырой markdown, ≤ 6 КБ на проект, срез по строкам «N️⃣ Workflow»). Страница берёт имя проекта из строки
   состояния (`[Имя](…/status.md)` — в DOM это текст между маркером и « · WF»), держит последнюю сводку в памяти
   окна (не в хранилище) и рисует в подсказке строки воркфлоу: `N️⃣ … ✅/💭/⬜/🛑 · о чём · роли`.
3. **Кнопка «Workflow»** (#5325) — первый пункт меню, иконка 🚀, без хоткея (⌘⌥W занят Claude). Клик: команда
   `{"action":"workflow","scope":"window","title":<AX>,"text":<KICKOFF.md>}` → страница вставляет текст в поле ввода
   (ProseMirror: фокус, `execCommand("insertText")` или `insertText` через DataTransfer/paste-событие — как надёжнее;
   черновик не затирать: вставлять в начало, если поле непустое) и НЕ отправляет. Перед этим приложение кладёт
   комплект `resources/workflow-kit/{WORKFLOW.md,KICKOFF.md}` в `~/Library/Application Support/MyClaude/workflow/`
   (`installLiveFiles` и первый клик). Если Accessibility нет — обычная команда всё равно уходит (файл-канал).
   Текст KICKOFF.md — в репозитории (оркестратор написал 01:40), батч B берёт как есть.
4. **Клавиши в меню** (#5326): подсказки убрать из заголовков пунктов; ставить `keyEquivalent` +
   `keyEquivalentModifierMask` (⌘⇧N, ⌘N, ⌘⌥↓ — `NSDownArrowFunctionKey`, ⌘⌥↑, ⌘⌥A, ⌘⌥S, ⌘⌥D) — AppKit рисует их
   справа серым сам. Тест «состав меню = README» переписать под `keyEquivalent`.
5. **Темы** (#5327): имена — Matrix → «Матрица», Dracula → «Дракула», Tokyo Night → «Токийская ночь»; порядок в
   themes.json и меню — по цветовому кругу: тёмные — Красная, Оранжевая, Жёлтая, Зелёная, Матрица, Бирюзовая,
   Токийская ночь, Синяя, Фиолетовая, Дракула, Сиреневая, Розовая, Малиновая, Коричневая, Серая; светлые —
   Персиковая, Лимонная, Кремовая, Мятная, Небесная, Светлая, Лавандовая, Сакура, Пудровая. id не менять.
6. **Тема на чат** (#5328). Ключи страницы: `chat:<заголовок>` (любое окно), `main` (главное окно как окно),
   `w:<заголовок>` (старые записи подчинённых окон — читать как `chat:`), `*`. Порядок восстановления по слою:
   session → `chat:<title>` → (главное окно: `main`) → `*`. Главное окно следит за `document.title` (MutationObserver
   на `<title>` + опрос 1 с) и при смене чата применяет запись `chat:` нового заголовка, а если её нет — свою
   `main`/`*`. **«Обкэшить» и «Новый чат» цвет не меняют**: новый чат записи `chat:` не имеет → остаётся тема окна;
   «Обкэшить» открывает окно с переносом — то же. Выбор в меню «Тема окна» пишет `chat:<title>` (и сессию);
   в главном окне дополнительно `main` — чтобы окно «в целом» тоже помнило. Swift-галка — по `chat:` через
   ThemeStore по заголовку (уже так).
7. **Категории шрифтов** (#5329): секции «С ЗАСЕЧКАМИ» (Georgia, Palatino, Baskerville, Didot, Hoefler Text,
   Iowan Old Style, Times New Roman), «БЕЗ ЗАСЕЧЕК» (Helvetica Neue, Avenir Next, Futura, Gill Sans, Optima, Verdana,
   Trebuchet MS, Arial, Tahoma), «РУКОПИСНЫЕ И ВЕСЁЛЫЕ» (Comic Sans MS, Chalkboard SE, Noteworthy, Marker Felt,
   Bradley Hand, Snell Roundhand, Papyrus, Copperplate, American Typewriter), «МОНОШИРИННЫЕ» (как сейчас).
   Поле `Font.category`. Размер шрифта — не делаем (слово Элвиса: ⌘+/⌘− хватает).
8. Гейт без простоев приложения: `bundle.sh` собирает заранее, потом `pkill → ditto → open` за 2 с (04.09 Элвис
   дважды попадал на «минус не работает» во время пересборки).
