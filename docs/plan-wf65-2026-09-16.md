## Риски

- Chin ниже редактора при растянутой коробке: если flex не отдаёт коробке высоту (какая-то обёртка держит
  `height`), редактор останется полосой сверху — гейт смотрит `.ProseMirror`/`ChatComposerEditor` высоту в probe.
- Возврат из широкого в узкий вид с текстом в поле: ступень берётся из хранилища, `natural` не испорчен
  (п. 4) — проверить сужением окна живьём.

  JS читает флаг с панели своего окна.
- `:has()` — по одному правилу на условие, не на узел.
