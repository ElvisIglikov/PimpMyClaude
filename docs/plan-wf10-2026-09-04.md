# План WF10 — «Автопокраска»: все окна гармонично по цветовому кругу

Дата: 04.09.2026 10:40. Проект ⚪PimpMyClaude. Задача 🟣Trelvis #5330. Слово Элвиса: «нажимаю кнопку — все окна меняются
гармонично по кругу; наборы и случайная; как радуга; трендовые, не кричащие, читать удобно». Оркестратор Fable high, батч,
критик и verify — Opus max. Ветка wf10. Run-файл `docs/run-wf10-2026-09-04.json`.

## Решение

1. **Где**: в меню на кнопке, после «🔤 Шрифт ▸» — подменю «🌈 Автопокраска ▸»: наборы → разделитель → «🎲 Случайно» →
   «🔁 Ещё раз» (повторить последний набор с новым случайным сдвигом) → «Как у Claude (все окна)». В меню-баре
   приложения — дубль подменю (окно под курсором не нужно).
2. **Наборы** (каждый — правило генерации, не список тем): «Радуга» (тёмные, hue равномерно по кругу от случайного
   старта), «Пастель» (светлые, по кругу), «Закат» (тёплые 350°–60°), «Океан» (180°–260°), «Лес» (70°–160°),
   «Ягоды» (280°–350°), «Неон» (тёмные с ярким акцентом), «Монохром» (один hue, разная светлость фона),
   «Случайно» — случайная схема из {аналоговая ±30°, триада, сплит-комплементарная, тетрада} и случайный старт,
   тёмная/светлая — по текущему режиму большинства окон (если окна светлые — светлая).
3. **Генератор палитры** (Swift, `AutoPaint.swift`): вход hue (0–360), light: Bool, «сила» 0–1; выход `palette`
   {accent, background, foreground, sidebar, panel, muted} в hex. Тёмная: background — HSL(hue, 35–45 %, 12–16 %),
   sidebar — L −3, panel — L +6, foreground — HSL(hue, 25 %, 92 %), muted — HSL(hue, 20 %, 65 %), accent — HSL(hue,
   80 %, 62 %). Светлая: background — HSL(hue, 60 %, 95 %), panel — 99 %, sidebar — 91 %, foreground — HSL(hue, 40 %,
   14 %), muted — HSL(hue, 25 %, 42 %), accent — HSL(hue, 70 %, 42 %). Контраст текст/фон ≥ 7 (проверка в тесте по
   формуле WCAG, при провале — подтянуть L). «Трендовые, не кричащие» — насыщенность фона ≤ 45 %.
4. **Раскладка по окнам**: окна Claude на экране (`ClaudeApp.onScreenFrames`, только стандартные, не свёрнутые),
   сортировка слева направо, затем сверху вниз; N окон → N hue по схеме набора (равномерно внутри диапазона; при N=1 —
   середина диапазона). Каждому окну — обычная команда темы `scope:"window"`, `title` = AX-заголовок, `theme` =
   `{id:"auto-<набор>-<hue>", name:"<Набор> · <hue>°", type, palette}`; через очередь CommandChannel (600 мс на окно).
   Окна без заголовка пропускаются. Тема записывается на чат как обычная (`chat:`), галки в «Тема» не ставятся.
5. **Память**: последний набор и старт — `UserDefaults autoPaint.last`; «Ещё раз» = тот же набор, старт +37°.
6. **Не делаем**: авто-перекраска новых окон, шрифты, анимация.
