## Батч A — `claude-patch/inject.js`

Требования 👾 Элвиса дословно: «полоска едва заметная, при наведении видимая», «двойные клики,
одинарные клики — важный функционал, сохрани как в ElvisOS», «после отправки сообщения не надо поле
сворачивать».

1. Идемпотентность: в начале `window.__myclaude?.dispose?.()`; в конце `window.__myclaude = {version, dispose, setStage, stage}`.
   `dispose` снимает ВСЁ: слушатели на элементах и на `window` (включая `myclaude-command`), observers,
   таймеры, `<style>`, атрибуты и inline-стили, возвращает штатную высоту редактора.
2. Ждать редактор: MutationObserver на `document.documentElement`, но обход троттлить (не чаще раза в
   250 мс, через `requestAnimationFrame`) и фильтровать по `affectsComposer` донора (6590–6607);
   переустанавливать ручку при пересоздании поля (React перерисовывает composer при смене чата).
   Если через 60 с редактора нет и URL не начинается с `https://claude.ai` — observer отключить.
3. Ручка: `<div id="myclaude-input-handle">` во всю ширину `.epitaxy-prompt`, сразу над ним, зона
   захвата 8px, видимая линия 2px, цвет `currentColor` с opacity **0.10** (едва заметна), при `:hover`
   и при перетаскивании 0.45, в свёрнутом состоянии 0.30 и полоска 80 % ширины по центру (как у донора).
   `cursor: ns-resize`, свёрнутая — `pointer`. Стили через `<style id="myclaude-input-handle-style">`;
   если `style.sheet` пуст или ловится `securitypolicyviolation` — написать в отчёте (резерв
   оркестратора: перенести CSS в `claude.css`).
4. Ступени и клики — **дословно как у донора**:
   - `COLLAPSED` (поле схлопнуто: блок `.epitaxy-prompt` скрыт `height:0;overflow:hidden;opacity:0`,
     ниже остаётся строка модели/кнопок — `collapseTargets` донора 5829–5887), `NORMAL` (штатная
     высота), `STRETCHED` (до потолка окна: верх поля почти под `.epitaxy-titlebar`, недобор 8px).
   - Одинарный клик (`onClick` 6761): `stage === COLLAPSED ? NORMAL : COLLAPSED` — из NORMAL и из
     STRETCHED одиночный клик схлопывает. Клик ждёт 260 мс возможного второго (`cancelClickStep` 6742).
   - Двойной клик (`onDoubleClick` 7019–7030): `stretchToMax()` до потолка; если уже у потолка
     (`atCeiling()`) — обратно в NORMAL.
   - Перетаскивание: как у донора (COLLAPSE_DRAG_SLACK 44, STAGE_DRAG_SLACK 26, MIN_HEIGHT 38,
     NATURAL_FALLBACK 96, CEILING_UNDERSHOOT 8, CEILING_RETRY_GAP 28, CLICK_SLACK 4).
   README п.1 («клик — шаг по ступеням») исправляет оркестратор под это описание.
5. Высота применяется как у донора: скролл-контейнер редактора получает `height/min/max-height`
   через переменную `--myclaude-input-height`, у самого `.tiptap` снимается `max-height:218px`
   (правила 5546–5550 донора: `EDITOR_ROOT_ATTRIBUTE`/`EDITOR_ATTRIBUTE`). Низ поля не уходит за
   край окна (`trimToViewport`, 5961).
6. Хранение: высота и ступень в `sessionStorage` (ключи `myclaude-input-height-v1`,
   `myclaude-input-stage-v1`). Отступление от донора (у него высота в `localStorage`) намеренное:
   новое окно не должно подниматься растянутым.
7. Команды: `window.addEventListener("myclaude-command", e => …)`. Команда приходит во ВСЕ окна,
   поэтому обрабатывать только если `document.hasFocus()`; `collapse` → `setStage(COLLAPSED)`,
   `expand` → `setStage(NORMAL)`, `cashout` → п. 8. Неизвестные — игнорировать.
8. `cashout` («Обкэшить», по ElvisOS: «перенесёт в поле ввода последний ответ и твой черновик»):
   текст последнего ответа ассистента (последний `[aria-label^="Message"]`, не внутри
   `.epitaxy-user-turn`; селектор уточнить по DOM, донор тут не помощник — у него нативный канал) плюс
   текущий черновик из редактора → `localStorage["myclaude-cashout"] = {at, text}`. Переход в новый
   чат делает Hammerspoon (⌘N). При установке в свежем чате (пустой редактор, запись моложе 90 с):
   вставить текст в редактор (`focus()` + `document.execCommand("insertText", false, text)`; если
   ProseMirror не принял — `paste`-событие с `DataTransfer`), запись удалить, поле в NORMAL.
9. Не делать: сворачивание после отправки, over-top, очередь сообщений, две секунды на стоп,
   автопрокрутку. Не трогать `claude.css`, `patch-claude.mjs`, `README.md` (правит оркестратор).
10. Проверка исполнителя: `node --check claude-patch/inject.js`. Отчёт текстом: что сделано, где и
    почему отступил от донора, что не проверено без живого Claude.

## Батч B — `hammerspoon/claude_minimize_menu.lua`

Правило дома (`~/.hammerspoon/init.lua`): **никаких event tap на mouseMoved/scrollWheel/keyDown/flagsChanged**.
Только `hs.timer` + `hs.mouse.absolutePosition()`. `hs.eventtap.keyStroke` — не tap, правило не нарушает.

1. Таймер 8 раз/с (0.125 с). Дёшево: app-объект кэшировать; на тике сначала сравнить курсор с кадрами
   окон Claude (`w:frame()`), и только если курсор в полосе 0–30 px от верха кадра — спросить
   `hs.axuielement.windowElement(w):attributeValue("AXMinimizeButton")` → `AXPosition`/`AXSize`
   (кэш 0.5 с). Проверено в живом Hammerspoon 1.1.1: кнопка есть, `AXPosition` возвращается
   (окно в 0,34 → кнопка в 39,50 размером 16×16). Курсор внутри кнопки ≥ 0.3 с → показать меню
   `hs.menubar.new(false):popupMenu(pos)` рядом с кнопкой (`popupMenu` есть, проверено). Повторно не
   показывать, пока курсор не уйдёт с кнопки (флаг, сброс по уходу). `popupMenu` блокирует Lua до
   закрытия — таймер это переживёт. Меню перекрывает быстрый клик по кнопке — как в ElvisOS, ожидаемо.
2. Пункты ровно: «Обкэшить», «Новый чат», «Свернуть», «Развернуть». «Свернуть/Развернуть» — это ПОЛЕ
   ВВОДА (решение Элвиса: пункты 6–7 ElvisOS без слова «поля»), не окно. Действия:
   - Свернуть/Развернуть → `w:focus()`, через 100 мс command `{action:"collapse"}` / `{action:"expand"}`;
   - Новый чат → `w:focus()`, `hs.eventtap.keyStroke({"cmd"}, "n", 0, app)`;
   - Обкэшить → `w:focus()`, через 100 мс command `{action:"cashout"}`, через ещё 400 мс ⌘N в то же окно.
   Команда пишется атомарно (tmp + `os.rename`) в `~/Library/Application Support/MyClaude/command.json`
   как `{"id": "<time>-<rand>", "action": "...", "at": "<ISO>"}`. Никакого `windowId`.
3. Экспорт: `M.start()/M.stop()/M.status()`, `return M.start()` в конце, по образцу
   `hammerspoon/claude_autoallow.lua`. Хоткеев не добавлять. Логи `print("[claude_minimize_menu] …")`.
4. Проверка исполнителя: `luac -p` (если есть) или `hs -c 'loadfile(...)'`; не подключать в
   `~/.hammerspoon/init.lua` — это делает 👾 Элвис по README.
