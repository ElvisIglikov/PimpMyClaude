# Полоска прогресса под полем ввода — что она показывает и что должна (05.09, к WF22)

## Как есть (по коду `claude-patch/inject.js`, раздел 2б)

1. Страница читает **последний ответ** в чате и ищет в нём строку состояния вида
   `💭⚪[Проект](docs/status.md) · WF N из M · идёт💭` (раньше — `· P%`). N и M — из этой строки.
2. Полоска — M сегментов; N−1 закрашены целиком, N-й — на долю P% (после отмены процентов — «идёт» = частично,
   «готово» = целиком). Нет строки состояния → полоска **прячется**.
3. Подсказка по клику на сегмент k: берёт сводку `status.md` проекта (приложение шлёт её командой `status` раз в
   2 с) и показывает блок с номером **k️⃣** — «о чём» и роли.

## Почему путает (слово Элвиса 05.09 19:00: «хуйня какая-то»)

- **Два разных счёта.** Счёт «WF N из M» с 04.09 идёт **по текущему чату**, а `status.md` нумерует воркфлоу
  **по проекту** (в PimpMyClaude — 13…28). Клик по 7-му сегменту чата показывает «7️⃣ полоска прогресса» из
  сводки проекта — чужой воркфлоу.
- Новый чат без строки состояния — полоска не пустая, а отсутствует; непонятно, «нет марафона» или «сломалось».
- В узком окне (280–350 px) текст подсказки не влезает, лишний значок ✅ у запланированного.
- Другие чаты (Trelvis) пишут строку по-старому (`WF 13 из 13 · 20%`) — пока не перечитали правила.

## Как должно быть (предложение оркестратора — в план WF22, до кодинга макет)

1. **Пустая полоска в новом чате**: M «пустых» сегментов не бывает, пока нет строки, — рисуем один пустой контур
   (без заливки); появилась строка — полоска раскладывается на M.
2. **Сегменты — по чату** (как строка), **подсказка — по проекту, по состоянию, а не по номеру**: клик по любому
   сегменту показывает сводку проекта целиком в сжатом виде: сколько воркфлоу / готово / потрачено, затем блоки
   💭 идёт (роли и эффорты, Fable max красным) и ✋ ждёт Элвиса (что именно ждёт). Номера status.md не
   сопоставляются с сегментами вовсе.
3. **Подсказка не шире окна**: ширина = окно минус поля, переносы строк; значок только состояния.
4. **Наведение — краткая строка** («WF 8 из 16 · идёт · PimpMyClaude»), клик — полная сводка.
5. Цвет сегмента по состоянию: идёт — акцент, ждёт Элвиса — жёлтый, упал — красный, готово — приглушённый.

Что не меняем: формат строки состояния (уже правило SkilZZZ), команду `status`, лоадер.
