## Решения по критику (обязательны для исполнителей)

1. **Хоткеи и ⌘Q — только Carbon `RegisterEventHotKey`** (как `hs.hotkey`), НЕ `NSEvent` global monitor
   (не глотает, просит Input Monitoring). Регистрировать/снимать по
   `NSWorkspace.didActivateApplicationNotification` (bundle `com.anthropic.claudefordesktop`) — это и есть «Claude впереди».
   Разрешений у приложения два: Accessibility и App Management. Уведомления — третье, необязательное.
2. **Закрывать Claude через `NSRunningApplication.terminate()` → `forceTerminate()`**, фильтр по `bundleURL`,
   НЕ `osascript` (apple-events entitlement + промпт «Автоматизация»).
3. **Порядок «Поставить»**: найти Claude по bundle id (`NSWorkspace.urlForApplication`, поддержать `~/Applications`,
   несколько копий — спросить) → проверить `access(W_OK)` на `Contents/Resources` и пробную запись (промпт
   App Management всплывает ДО закрытия Claude; после «Разрешить» повторить автоматически; не-админ →
   текст «зайди под админом или переустанови Claude в ~/Applications») → quit → бэкап → патч → хэш →
   codesign ad-hoc → открыть Claude.
4. **Статус «стоит/слетел»** без парсинга asar: сравнение `CFBundleShortVersionString` + `ElectronAsarIntegrity`
   с записанными при «Поставить»; проверка при активации Claude и раз в 60 с; одно уведомление «Поставить снова».
5. **Автозапуск при входе**: `SMAppService.mainApp.register()` + тумблер, по умолчанию вкл.
6. **asar читать через `Data(contentsOf:options:.mappedIfSafe)`** (178 МБ).
7. **Меню на кнопке**: `Timer` 8 Гц + `NSEvent.mouseLocation`, рамки окон из `CGWindowListCopyWindowInfo` по PID,
   AX только для прямоугольника кнопки; `NSMenu.popUp` требует `NSApp.activate` → после закрытия меню вернуть
   фокус окну Claude (AXRaise). 7 пунктов и клавиши как в README. ⌘Q-блок — тумблер, по умолчанию вкл, алерт с «как выйти».
8. **«Снять»** = restore из бэкапа + переподпись ad-hoc; в README команды честно: подпись Apple не вернётся,
   настоящий откат — переустановка Claude.
9. Dev-сборки с первого билда подписаны Developer ID через `tools/bundle.sh` (стабильный DR → Accessibility один раз).
10. Swift 5 mode, macOS 13 target — без битвы с Sendable.
