## Цель

Одно приложение `PimpMyClaude.app` (Swift, AppKit, без Node и Hammerspoon), подписано
«Developer ID Application: ELVIS IGLIKOV (F27N4S4NJ4)», нотаризовано, раздаётся zip. Двойной клик →
кнопка «Поставить» → всё работает. Что оно делает — ровно то, что сегодня делают
`claude-patch/patch-claude.mjs` + `inject.js` + `claude.css` + три Lua-модуля (см. README).

## Что есть (переносить точечно, не переписывать логику)

- Патчер `claude-patch/patch-claude.mjs` (≈420 строк): формат asar (заголовок-pickle, сдвиг смещений,
  integrity), лоадер v6 (строка `LOADER`), Info.plist `ElectronAsarIntegrity`, `xattr -cr`, `codesign`
  ad-hoc с `entitlements.plist`, бэкап, restore, отказ работать изнутри Claude, поиск процессов по пути.
- Живые файлы в `~/Library/Application Support/MyClaude/`: `claude.json`, `claude.css`, `inject.js`
  (лоадер читает их при изменении). Приложение кладёт свои копии туда же (папку НЕ переименовывать —
  лоадер v6 у Элвиса уже смотрит в `MyClaude`).
- Hammerspoon-модули: `claude_autoallow.lua` (AX-обход окон, AXPress на «Allow…», флаг
  AXManualAccessibility каждый тик), `claude_minimize_menu.lua` (опрос курсора 8 Гц, AXMinimizeButton,
  popup-меню 7 пунктов с иконками, горячие клавиши только когда Claude впереди, команды через
  command.json, «Расставить» столбцами с сохранением порядка, «Показать»), `claude_noquit.lua`.
- macOS-грабли, уже пройденные: запись в /Applications требует права «Управление приложениями» (App
  Management) — у приложения своя запись в TCC, попросить при первом «Поставить»; Claude после
  перезапуска сбрасывает AXManualAccessibility; `hs`-подход к синтетическим кликам не нужен.

## Требования к поведению (кратко, детали в README текущего репозитория)

1. «Поставить»: проверяет Claude в /Applications, версия, лоадер; закрывает Claude по-хорошему; бэкап
   `app.asar`+`Info.plist` в `~/Library/Application Support/MyClaude/backups/<версия>/`; патч; хэш;
   `codesign` ad-hoc; открывает Claude. Ошибки — человеческим текстом с кнопкой «Открыть настройки».
2. «Снять»: restore из бэкапа, переподпись, открыть Claude.
3. После обновления Claude: уведомление с кнопкой «Поставить снова».
4. Значок в строке меню: статус (стоит / слетел / Claude не найден), тумблеры авто-Allow и меню.
5. Ничего не звонит наружу, никакой телеметрии. Только файлы в Application Support.
6. Названия и состав меню/клавиш — как в README (Обкэшить ⌘⇧N, Новый чат ⌘N, Свернуть ⌘⌥↓,
   Развернуть ⌘⌥↑, Расставить ⌘⌥A, Показать ⌘⌥S, Прокрутить ⌘⌥D).
