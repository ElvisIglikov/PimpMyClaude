## Зачем срочно

Волна 2 прямо сейчас делает #5768 «Обкэшить заменяет окно»: новое окно встаёт на место старого,
**старое закрывается**. ElvisOS ходил этой дорогой и вынес правило: исходное окно портить ПОСЛЕДНИМ
действием, по факту доезда текста, а не по факту появления окна — между «окно появилось» и «текст лёг
в поле» у страницы пять путей отказа. До #5768 молчаливый промах стоил пустого нового чата; после
#5768 он стоит **потерянного навсегда текста Элвиса**. Это блокер, и чинить его надо в том же дне.

## Батчи

### Батч Ц — закрытие донора по доезду (Swift + страница; один писатель на файл, батчи по очереди)
Задачи #5779 (закрывать по доезду), #5780 (подтверждать вставку), #5781 (черновик не роняет перенос),
#5784 (молчаливый выход = «кнопка не работает»), #5785 (потолок ожидания = сумма пауз).
- Страница: подтверждение вставки — нормализованное сравнение (NBSP → пробел, схлопнуть пробелы),
  голова 40 знаков или 90 % длины, до 12 повторов по 150 мс, затем второй способ вставки
  (`execCommand("insertText")`) и ещё 20 повторов; запись переноса чистится ТОЛЬКО после подтверждения.
  Вставка поверх выделения всего поля — чужой черновик больше не отказ. Каждая развилка говорит причину.
- Swift: `cashoutTick` закрывает донора не по новому id окна, а по подтверждению доезда (страница уже
  держит `cashoutState()`); отказ-приговор — окно НЕ трогаем и говорим плашкой; потолок ожидания
  считается суммой пауз худшего честного хода, а не «на глаз».

### Батч В — вложения (#5773, #5782, #5783)
ElvisOS вложения переносил: файлы из поля ввода (реестр, который инжект набивает на входе) и картинки
из ленты (`data:`/`blob:`), потолки 24 штуки / 48 МБ, дедуп по хэшу содержимого, вставка ПОСЛЕ текста
и только недостающих, проверка мультимножеством (имя, размер) до 40 проходов.
- **В localStorage вложения не влезут**: квота origin ~5 МБ на ВСЕ наши ключи разом, base64 раздувает
  на треть, `setItem` у нас под глухим try/catch — один retina-скриншот съедает всё молча. Нужен свой
  канал через диск, как `fork-carry` у ElvisOS (куски, отдельная папка, права 0600, уборка).
- Считать штуками, а не именами: восемь скриншотов macOS все зовутся `image.png`, Claude склеивает
  одинаковые имена в одно вложение — имена разводить суффиксом.
- Байты НЕ гонять строкой через `probe.js`: канал общий и ответ уже весит мегабайты.

### Батч О — уроки по окнам (#5784 часть, #5785 часть, AX)
Таймаут AX окна ставится отдельно от приложения; свежему окну рамка ставится в порядке
«размер → позиция → размер» (система урезает высоту по краю экрана под Dock); `kAXRaise` не поднимает
окна над чужими приложениями без активации; у каждого экземпляра Claude есть пара служебных окон
800×600 — их надо отсеивать; прозрачные окна (alpha < 0,05) и мелочь меньше 200×150 не занимают место
при поиске свободного прямоугольника; свежее окно нельзя спрашивать сразу после смены рамки (пауза 0,35 с).

## Что НЕ брать из ElvisOS

Второй процесс Claude вместо попапа; разворот окна «на четыре пятых экрана» при переносе (Элвис его
прямо отменил); замена окна в пункте «Новое окно» (тоже отменена им); опрос по таймеру там, где хватает
сторожа за папкой.
