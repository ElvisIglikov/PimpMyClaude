## Контракт канала «Пимп» (JSON по именам и типам; эталоны — `tests/fixtures/pimp/*.json`, читают ОБА батча)

Каталог `~/Library/Application Support/MyClaude/pimp/`. **Файл на запрос** `<id>.json` (id = `<unix-мс>-<4 цифры>`,
права 0600), ответ — `<id>.result.json` рядом. Приложение на общем тике 2 с: берёт запросы без ответа,
по `at` по возрастанию, **исполняет, если `at` младше 30 с** (старше — пишет ответ `ok:false, error:"stale"`);
исполняет по одному; пока идёт `new-window` (до 40 с), остальным сразу `ok:false, error:"busy"`.
Правда об исполнении — ответ на диске, не память процесса (перезапуск приложения на гейте ничего не теряет
и не повторяет). Файлы старше часа приложение убирает на тике. Claude не запущен или окон нет →
`ok:false, error:"no-windows"`. CLI ждёт свой ответ до 60 с; ответа нет 5 с и файл запроса лежит нетронутым →
«Пимп не запущен» (приложение при взятии в работу пишет `<id>.taken`).

Запрос: `{"id","at":"<ISO UTC>","action":"new-window"|"arrange"|"projects"|"windows","from":"<local_… или \"\">",…}`.
Ответ: `{"id","at","ok":bool,"error":"<строка или \"\">","fromResolved":bool,"screen":"main",…}`.

- `new-window`: `"project":"<имя папки или абсолютный путь>","place":"left"|"middle"|"right"|"below"|"above"|"<x>,<y>"`.
  Папка: `projects.json` → индекс Claude → путь; не нашли → `error:"project-missing"`, в ответ `"projects":[имена]`.
  Зовёт тот же `newWindow(in:on:)`, что пункт меню (`text`/`name`/слои — как в меню + п. 4). Ждёт появления
  НОВОГО окна Claude (появившегося после запроса, не по имени — переименование может не удаться) до 40 с;
  не дождались → `ok:false, error:"window-missing"` (чат создан — сказать в `error`). Потом расстановка:
  `left/middle/right` — порядок = `ArrangeLayout.order(of:)` существующих окон + новое по индексу
  (`ArrangeLayout.insert(order:count:at:)`, чистая арифметика) и `arrange(order:)`; при чётном числе «middle» —
  правее середины; окон больше, чем столбцов (`columns(count:width:)`), — ряды, «middle» = середина первого
  ряда, фактический `frame` в ответе. `below`/`above` — столбец окна `from` делится пополам по высоте
  (порог 360 pt, иначе `error:"too-small"`), остальные не трогаются; `from` не нашли → как `right`. `x,y` — как
  в меню. Ответ: `"window":{"title","chat","frame":[x,y,w,h]},"layers":"<status().newWindow.layers или \"\">"`.
- `arrange`: `"layout":"row"` — сегодняшнее «Расставить». Ответ `"windows":[…],"minimized":<число>`.
- `projects`: `"projects":[{"name","folder","lastUsed":"<ISO>"}]` по `lastUsed` убыв.
- `windows`: `"windows":[{"title","chat":"<или \"\">","folder":"<или \"\">","frame"}],"minimized":<число>` —
  `chat`/`folder` только при живой карте `ChatProbe`, иначе пустые строки.
- `minCellWidth` — из живого `claude.json` (`minWindowWidth`, fallback 360), не константа 340.

`projects.json` (WF30 ч.2): `{"version":1,"projects":[{"name","folder","lastUsed"}]}` — пополняется на тике из
индекса Claude и на каждый клик меню / запрос `new-window`; пропавшие с диска папки не показываются, из файла
не удаляются. Источник для меню подменяется в замыкании `menu.recentProjects` (`ClaudeAXController.swift:~131`),
`ProjectIndex` не трогать (тесты `ProjectTests.swift:217-302` целы). Лимит меню прежний (8).
