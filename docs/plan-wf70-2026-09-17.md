## Решено (не переспрашиваем)

- Верхний уровень меню = оформление; всё остальное — под «⋯ Ещё ▸». Клавиши не меняются (регистрация по
  `MenuModel.entries`, не по видимости).
- Мои темы — первым разделом; у каждой своей темы подменю; «Тема проекта» — первым пунктом раздела.
- «Размер вопросов» из меню убирается, контракт `size.question` остаётся (страница и старые файлы).
- «Всем окнам ▸» уходит с верхнего уровня; по слову критика — последним пунктом «⋯ Ещё ▸», а не в никуда:
  там единственные тумблеры «Цвет по проекту», «Раскрасить по кругу» и «Живые цвета» (выключил однажды — включить
  было бы негде). Единственный вопрос Элвису в макете: в «Ещё ▸» (рекомендую) или совсем.
- «💾 Сохранить тему» — ОДИН пункт в разделе «Мои темы» (слово Элвиса 14:20: «без „мою“, без многоточия —
  сохранить тему и всё, и она чик сразу появляется сверху»): клик сохраняет текущий вид окна БЕЗ диалога с именем
  (`themeToSave` — последний применённый цвет; имя автоматом — имя цвета окна, при совпадении с уже сохранённой
  добавляется « 2», « 3»…), новая тема встаёт ПЕРВОЙ в списке. Переименовать — через «✏️ Изменить…» (редактор при
  сохранении спрашивает имя, как сейчас). «➕ Своя тема…» из меню уходит (слово Элвиса: «плюс своя тема не нужно»).

  «Только этому окну» / «Окнам проекта <Имя>» (есть, если окно опознано проектом) / «Всем окнам».

**Устройство.**
1. Подвал карточки (`progressCardFoot`) больше не показывает счёт проекта. `progressFoot` и регэкспы
   `PROGRESS_FOOT_*` удаляются вместе с тестами на них (#5910/#5911 закрыты словом Элвиса 17.09: «убери»; #5916
   закрывается тем же — узла нет). Вместо него — `progressWhen(block, now, updated)`: ЧИСТАЯ функция (без
   `Date.now()` внутри, экспорт через люк `__myclaudeTest`), одна человеческая строка про ЭТОТ воркфлоу.
   Дата в сводке есть только в строке «обновлено 12:40 / вчера 03:10 / 15.09» — `statusParse` (ветка `if (!current)`,
   порядок проверок блока не трогать) захватывает её в поле `updated: {kind: "today"|"yesterday"|"date", time}`.
   Относительные слова («только что», «N мин назад», «N ч назад», «идёт N мин») — ТОЛЬКО когда файл обновлён
   сегодня и конец/начало ≤ now; иначе честно абсолютом:
   - ✅ готов, сегодня, конец ≤ now: «Завершился только что» (< 1 мин) / «Завершился 15 мин назад» / «Завершился
     2 ч назад»; файл не сегодняшний или конец > now: «Завершился вчера в 10:35» / «Завершился в 10:35»
     (kind date — «Завершился 15.09 в 10:35»). Всегда « · занял 50 мин» — из хвоста `time` после последнего « · »,
     нет хвоста — разница «09:45 → 10:35» (переход через полночь: +24 ч).
   - 💭 идёт: «Идёт 25 мин · начался в 13:05» (длительность от начала до now, если файл сегодняшний; иначе «Идёт ·
     начался в 13:05»), + « · закончит в 13:50», если в `time` есть «закончит» (парсер — нынешний `progressTime`,
     он остаётся ради этого; тест «„примерно“» (#5909) переписывается на него как на парсер).
   - ⚠️ ждёт: «Ждёт тебя · идёт 40 мин» (тот же расчёт).  ⬜ запланирован: «Ещё не начат».
   - Времён в блоке нет: «Завершился» / «Идёт» / «Ждёт тебя» одним словом; для найденного блока строка никогда не пустая.

   `block.steps` продолжает считаться для заливки сегмента).
