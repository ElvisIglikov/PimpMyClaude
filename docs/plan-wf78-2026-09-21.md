## Решения

1. **Только подмена текста в родных узлах Claude + одна дорисованная полоса.** Скрипт без нейросети: новый раздел
   `inject.js` «12ж. Панель лимитов». Наблюдатель за `body` (childList, subtree выключен где можно) ловит появление
   `div[role="dialog"][data-cds="Popover"]`, внутри которого есть `[data-cds="StackedMeter"]` и `a[href="/settings/usage"]`
   (опознание по устройству, не по английскому тексту); пока панель открыта — наблюдатель за ней самой (React
   перерисовывает числа), подмена идемпотентна (сверяем итоговый текст, своё не переписываем — без петли). Всё снимается в
   `dispose()` (реестр `track`). Не опознали узел — НЕ трогаем ничего (родной английский лучше сломанного).
2. **Тексты** (правая колонка — что пишем):
   - «Context window» → «Контекст»; «324.7k / 1M (32%)» → «325k / 1M (32%)» (тысячи без десятых, округление;
     миллионы как есть). `aria-label` кружка и StackedMeter не трогаем.
   - «Plan usage limits · Max (20x)» → «Elvisnya · Max 20x»: имя аккаунта + тариф без скобок. Имя: главное окно читает
     `button[data-testid="user-menu-button"]` (текст минус первая буква-аватар, до «·») и кладёт в `localStorage`
     (`myclaude-account-v1`); любое окно читает оттуда. Имени нет — «Max 20x» без имени. Тариф — из родной строки после «·».
   - «5-hour limit» → «5-часовой»; «Resets in 4 hr 9 min» → «4 ч 9 мин — в 01:25» (время сброса = сейчас + интервал,
     24 часа, минуты с нулём); процент у этого блока СКРЫТ (`display:none` своим атрибутом, узел не удаляем).
   - «Weekly · all models» → «Недельный»; «Resets Fri 8:00 AM» → «Пт 08:00» (Mon…Sun → Пн…Вс, AM/PM → 24 ч);
     процент остаётся. Если вместо дня недели придёт «Resets in …» — формат как у 5-часового, процент остаётся.
   - «Weekly · Fable» → «Fable» (общее правило: «Weekly · X» → «X», «all models» → «Недельный»); правая часть так же.
   - «See detailed breakdown» → «Статистика». Незнакомую строку не трогаем.
3. **Полоса «Сброс через 3 дня 6 часов»** — дорисовывается ПОСЛЕ последнего блока лимитов, внутри того же столбца
   (`div.flex.flex-col.gap-sm`): строка-заголовок теми же классами, что у родных блоков (слева «Сброс через N дн M ч»
   по-русски с верным склонением: «3 дня 6 часов», «1 день 1 час», «5 часов 20 минут» когда меньше суток), под ней полоса
   той же высоты 4 px из 7 отрезков с зазором 1 px: прошедшие дни залиты `bg-fill-accent`-цветом, текущий залит
   частично, будущие — дорожка; под полосой мелкие подписи дней недели лимита, начиная со дня сброса (сброс Пт 08:00 →
   «Пт Сб Вс Пн Вт Ср Чт»), сегодняшний ярче. Момент сброса считается из недельной строки («Fri 8:00 AM» → ближайшая
   будущая пятница 08:00 местного времени; «Resets in …» → сейчас + интервал); неделя = 7 суток до него. Недельной строки
   нет — полосу не рисуем. Свой узел помечен `data-myclaude-week`, один на панель.
4. **Кружок в режиме чтения (#6737)**: когда поле ввода свёрнуто (автосвёртка/ручка), кружок остаётся видимым и
   нажимаемым на своём месте справа внизу — «плавает» поверх ленты; под ним зеркальный угловой фейд (как левый верхний
   #6656/#6658, только в правом нижнем углу, того же размера и прозрачности); больше в углу ничего. Панель по клику
   открывается родная (и русифицируется п. 1–3). Поле развернули — кружок возвращается в строку как был. Как именно
   достать кружок из свёрнутого поля (CSS-исключение из правила свёртки, `position: fixed` на кнопке, без переноса узла в
   DOM — React его потеряет) — решает исполнитель по устройству раздела «Сворачивание»/«Автосвёртка»; узлы React не
   переносить и не клонировать.
5. **Границы**: `aria-label` и подсказки (tooltip) сегментов не переводим; страницу `/settings/usage` не трогаем; в
   широком виде окна (три колонки) поведение то же.

6. **Самовосстановление узлов Пимпа (#6766, слово Элвиса 21.09 00:35: «в окне ChinaAI поля ввода нету и элементов
   управления… разобраться, чтобы в будущем так не происходило»).** Диагноз живьём: поле свёрнуто автосвёрткой, а свои
   узлы (`#myclaude-input-handle`, рамка окна, полоска, карточка, рейка) исчезли из `body` попапа — у `body` остался один
   ребёнок из шести (Claude пересоздал содержимое), страница не заметила: `status().handleVisible` = true при
   отсутствующем узле; вернулось только повторным запуском инжекта. Лечение: дешёвая проверка `isConnected` своих узлов
   на уже существующем стороже (без новых таймеров и наблюдателей); пропали — поставить заново тем же путём, что на
   инжекте (идемпотентно), и пересчитать раскладку; `handleVisible` считать по живому узлу. Тест: снести узлы из `body`
   стенда → следующий круг сторожа вернул их, поле снова разворачивается полосой.

## Риски
- Claude сменит устройство панели — опознание по устройству откажет, панель останется родной английской (не сломается).
- Мигание английским на кадр при перерисовке: подмена в колбэке наблюдателя идёт до отрисовки кадра (микрозадача) — проверить живьём.
- Кружок `position: fixed` внутри контейнера с `transform`/`overflow:hidden` может обрезаться — тогда исключать кружок из
  свёртки на уровне правил раздела «Сворачивание», а не вытаскивать.
