Решено, не переспрашиваю

  • Только в широком окне; в узком поле ввода остаётся как сегодня (там картинки сверху и потолок в четверть окна, чтобы не съедали черновик).
  • Кнопка отправки остаётся на своём месте справа внизу; текст под неё не заходит — последняя строка стоит выше кнопки.
  • Крестик снятия вложения не трогаем: по нему «Обкэшить» считает картинки.
  • Размер текста в поле ввода по колёсику мыши делает Астра — её правка сейчас в работе, я в тот же файл не лезу, пока она не сдаст.
