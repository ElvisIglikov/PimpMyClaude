## Что есть в ElvisOS (разведка 17:10)

- Темы — JSON-палитры из 6 цветов (`accent, background, foreground, sidebar, panel, muted`) + `type` dark/light,
  `Resources/sol-theme-presets.json` (10 тем) и `codex-theme-presets.json` (43). CSS генерируется из палитры
  (`claude-theme-manager.mjs:402-482` хелперы, `:579-861` `generateThemeCss`): корневой селектор
  `:root, html, body, [data-mode], .cds-root, .dark/.light, .darkTheme/.lightTheme, .dframe-root`, HSL-триплеты
  `--bg-000…500`, `--text-000…500`, `--accent-*`, `--border-*`, `--oncolor-*`, готовые `--claude-*`, `--surface-*`,
  `--df-bg-sidebar`, `color-scheme`, хвост из правил фон/сайдбар/selection/caret. Всё с `!important`.
- Доставка — один файл CSS на все окна через `insertCSS`. **Per-window тем в ElvisOS нет.**
- Замороченное (не переносим): патч asar под темы, редактор тем, пипетка, избранное, Epitaxy-блок для Claude Code,
  70 переменных `--cds-gray/blue-*`, `--tw-prose-*`, скроллбары.

## Решение

Лоадер v6 НЕ трогаем (без перепатча Claude). Тема живёт в странице: `inject.js` уже исполняется в каждом окне и
получает команды `command.json` → событие `myclaude-command`. Окно адресуется заголовком (`document.title`), как
«Обкэшить».

1. **Каталог тем** — `claude-patch/themes.json`: 8–10 тем формата sol (id, name, type, palette). Набор: фиолетовая
   (главное окно), синяя (Trelvis), зелёная (Dictatorik), оранжевая (Vkusnoff), Matrix, Dracula, Tokyo Night, светлая
   Arctic, серая нейтральная, «Как у Claude» (сброс). Один источник: bundle.sh копирует в Resources, патчер — в
   Application Support (для справки), Swift читает из бандла для названий меню.
2. **Движок в inject.js**: порт урезанного `generateThemeCss` (~120 строк JS), `<style id="myclaude-theme">` в `<head>`,
   команда `{action:"theme", scope:"window"|"all", title, theme:{id,name,type,palette}|null}`. Окно с `scope:"window"`
   применяет, только если `document.title === title` (пустой title → окно в фокусе). Запоминание: `sessionStorage`
   (тема этого окна на время его жизни, переживает навигацию) + `localStorage` карта `title → theme` (после
   перезапуска Claude окно с тем же заголовком снова красится) + `localStorage` «тема для всех» как запасная.
   Перезапись `data-mode`/`color-scheme` под `type`. `__myclaude.status()` показывает тему.
3. **Меню на кнопке «Свернуть»**: подменю «Тема окна ▸» (список тем, галка у текущей, «Как у Claude») и «Тема всех
   окон ▸». Хоткеев нет. Swift берёт заголовок окна из AX (`kAXTitle`, как для cashout) и пишет `command.json`
   с палитрой (страница файлов не читает).

## Разбор плана (критик недоступен, разносил оркестратор)

1. **Каскад CSS.** `claude.css` лоадер вставляет как user-стили (`cssOrigin:"user"`); по спецификации каскада
   user `!important` сильнее author `!important`. Тема из inject.js — author. Конфликта нет: в claude.css нет
   цветов (стрелки, строка действий). Стили самого Claude — author без `!important` → тема их бьёт. Зафиксировано.
2. **Ключ окна — не только заголовок.** Заголовок главного окна меняется при каждом переходе между чатами →
   карта title→theme перекрашивала бы главное окно на каждом чате. Решение: тип окна по `location.href` —
   главное (claude.ai) хранит тему под ключом `main`, подчинённые (`about:blank`, «Open in new window») — под
   своим заголовком (они привязаны к одному чату). `sessionStorage` — первичное хранилище на жизнь окна
   (уже используется для высоты поля, у каждого окна своё — проверено), `localStorage` — карта на перезапуск.
3. **Формат команды (контракт A↔B, менять только на гейте):**
   `{"id":"<мс-рандом>","action":"theme","at":"<ISO>","scope":"window"|"all","title":"<AX-заголовок окна>",
   "theme":{"id":"violet","name":"Фиолетовая","type":"dark","palette":{"accent":"#…","background":"#…",
   "foreground":"#…","sidebar":"#…","panel":"#…","muted":"#…"}}}`; `"theme":null` — сброс («Как у Claude»).
   `scope:"window"` — применяет окно с `document.title === title` (пустой title → окно в фокусе), как cashout.
4. **Упрощения:** пункт «Тема всех окон» в меню-баре приложения — убрать (есть в меню на кнопке); копия
   themes.json в Application Support — убрать (Swift читает из бандла, страница получает палитру в команде).
   `installLiveFiles` не трогать → B не пишет в Patcher.swift.
5. **data-mode не переключаем** (в ElvisOS для этого пишут config.json Claude — замороченно). Тема выставляет
   `color-scheme` и переменные; светлая тема поверх тёмного режима Claude может выглядеть неровно — в первой
   версии каталог в основном тёмный, светлая одна (Arctic) с пометкой.
6. **Идемпотентность:** dispose снимает `<style>`; при перезагрузке inject.js тема сразу восстанавливается из
   sessionStorage/localStorage (до отрисовки ручки). Ручка/cashout/scroll не трогаются — тема отдельный модуль
   внутри IIFE с собственными ключами хранилища `myclaude-theme-*`.
7. **Гейт без «Поставить»:** inject.js кладётся в Application Support — лоадер перечитывает по mtime;
   `probe.js` возвращает `{title, href, bg: getComputedStyle(document.body).backgroundColor, theme:
   __myclaude.status().theme}` по каждому окну → видно, какое окно какого цвета.
8. **Lua-модули** не обновляем: Элвис и команда на приложении; в README пометить, что темы — только в приложении.
9. Модели: A, B — Opus max; V-A, V-B — Opus max; сверка — Opus max. Fable только оркестратор.
10. **Сборка:** `swift build/test` — B; A только JS (проверка синтаксиса `node --check`). Живой прогон — оркестратор.
