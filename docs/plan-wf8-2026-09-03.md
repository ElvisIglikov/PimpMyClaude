# План WF8 — Предпросмотр темы и шрифта при наведении

Дата: 04.09.2026 00:10. Проект ⚪PimpMyClaude. Задача 🟣Trelvis #5323. Слово 👾 Элвиса: «навожу: красный, жёлтый,
оранжевый — тык-тык-тык, цвета меняются сразу у текущего окна; шрифты так же; потом на каком-то остановился и нажал».
Одна задача, два файла — без критика, с verify. Оркестратор Fable high, батчи и verify Opus max. Стартует после WF7
(inject.js — один писатель). Run-файл `docs/run-wf8-2026-09-03.json`.

## Решение

1. **Контракт (дополнение к п. 5 WF6, порядок полей `id, action, at, scope, title, preview, theme, font`):**
   `"preview": true` — страница применяет слои из команды только в таблицы стилей, хранилище НЕ трогает;
   `"preview": false` без `theme`/`font` — «конец предпросмотра»: страница восстанавливает слои из хранилища
   (session → window → "*" → ничего). Обычная команда (без `preview`) закрепляет, как сейчас. `scope` для
   предпросмотра всегда `window`.
2. **Swift:** подменю тем и шрифтов получают `NSMenuDelegate.menu(_:willHighlight:)`: пункт темы → `previewTheme(theme)`,
   пункт шрифта → `previewFont(font)`, «Как у Claude» → предпросмотр сброса (`theme:null` / `font:null` с `preview:true`),
   заголовки/разделители/«Всем окнам»/«Сохранить…» → ничего. Выбор пункта — как сейчас (закрепляющая команда).
   `menuDidClose` корневого popUp: если закрепляющей команды не было — послать «конец предпросмотра».
   Троттлинг не нужен: лоадер читает command.json раз в 500 мс и берёт последнее; но id обязан быть новым.
   Между preview и закрепляющей командой — пауза ≥ 600 мс не требуется: закрепление пишет те же слои.
   Подменю «Всем окнам ▸» предпросмотра не делает (красить все окна на наведении — шумно).
3. **inject.js:** `runThemeCommand`: при `preview === true` — `applyTheme/applyFont` без `setMapLayers/storeSessionTheme`,
   `themeState.previewing = true`; при `preview === false` — `restoreTheme()` по слоям из хранилища и
   `previewing = false`. `status().preview`. Ручка/cashout не задеты.

## Гейт

Ведёшь мышью по темам — окно перекрашивается сразу; ушёл из меню без клика — вернулось сохранённое; кликнул —
закрепилось; шрифты так же. В релиз 1.2.0 вместе с WF6/WF7.
