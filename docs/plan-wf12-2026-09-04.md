# План WF12 — Размер шрифта (ответы/вопросы) и подсказка полоски по клику на сегмент

Дата: 04.09.2026 11:15. Проект ⚪PimpMyClaude. Задачи 🟣Trelvis #5341, #5342, #5343 (неоновая рамка). Стартует после WF10 (Swift-меню) и WF11
(inject.js): оба файла заняты. Оркестратор Fable high, батчи и verify Opus max, без критика (две небольшие правки).
Run-файл `docs/run-wf12-2026-09-04.json`.

## Решения

1. **Слой размера** — третий независимый слой рядом с `theme` и `font`: `"size": {"answer": 15, "question": 14}`
   (px, 11–24; любое поле может отсутствовать → не менять; `null` слоя → сброс). Контракт команды `theme`: порядок
   `id, action, at, scope, title, preview, theme, font, size`. Хранилище страницы — та же трёхзначная запись
   `{theme, font, size}`, тот же приоритет и предпросмотр. CSS: только текст сообщений — ответы:
   `.font-claude-response, .font-claude-response-body, [data-testid="assistant-message"] .prose` → `font-size: Npx
   !important; line-height 1.5`; вопросы: `[data-user-message-bubble], .epitaxy-user-turn` → `font-size`. Заголовки/код
   в ответах масштабируются пропорционально через `em` (код 0.9em). Другие элементы (кнопки, сайдбар, поле ввода)
   не трогать. Точный селектор ответов проверить на гейте по DOM (probe).
2. **Меню**: в подменю «🔤 Шрифт ▸» после секций — разделитель, «Размер ответов ▸» (12, 13, 14, 15, 16, 18, 20, «Как у
   Claude»), «Размер вопросов ▸» (то же), с галкой и предпросмотром при наведении; «Всем окнам ▸» внутри каждого. Память
   `ThemeStore.sizeByWindow/sizeAll`; «Мои темы» сохраняют и `size`.
3. **Подсказка полоски — по клику**: наведение ничего не показывает (только курсор pointer над линией ±4 px);
   `pointerdown` в полосе (capture, `preventDefault` только внутри полосы ±4 px по вертикали) → определить сегмент по x
   → подсказка со строками сводки ТОЛЬКО этого воркфлоу (`N️⃣ …` + роли), заголовок «Воркфлоу N из M · состояние»;
   для сегментов без сводки — «Воркфлоу N · готов/идёт/запланирован». Повторный клик по тому же сегменту, Esc, клик
   мимо — скрыть. Клик по другому сегменту — переключить. `status().progress.tip = {segment, open}`.

4. **Неоновая рамка окна** (#5343, слово Элвиса 11:25: «как полоска, того же цвета и толщины, по скруглениям окна,
   ровненько; кто-то включит, кто-то нет»). Четвёртый слой `"frame": true` (null — выкл), хранится/предпросматривается
   как остальные. Страница: fixed-оверлей `inset:0`, `pointer-events:none`, `z-index` ниже подсказок/меню, `border-radius`
   = радиус окна macOS (10 px; на гейте сверить по скриншоту, при необходимости 12), `box-shadow: inset 0 0 0 2px
   <accent>, inset 0 0 18px <accent>, inset 0 0 6px <accent>` — тот же цвет и свечение, что у полоски (акцент темы,
   без темы — акцент Claude). Меню: тумблер «✨ Неоновая рамка» в конце подменю «🎨 Тема ▸» (для окна) и в «Всем
   окнам ▸». Полоска и рамка не спорят: полоска поверх.
