## Как считалось

- Источник — транскрипты Claude Code `~/.claude/projects/*/*.jsonl` (+ `<session>/subagents/*.jsonl`), Node-хелпер
  (2500 строк). Оборот ответа = input + output + cache_read + cache_creation; **один ответ считается один раз по
  `message.id`** — иначе завышение в 1,9× (#2784: один ответ лежит несколькими строками с копией usage).
- Цена по API за ответ по модели ответа: input·Pin + cache_read·Pin·0.1 + write5m·Pin·1.25 + write1h·Pin·2 +
  output·Pout. Прайс (сверен 10.08.2026): Fable 5 — $10/$50; Opus 5 — $5/$25; Sonnet 5 — $3/$15; Haiku 4.5 — $1/$5;
  незнакомая модель — ставка Opus с пометкой; прайс «протухает» через 120 дней с предупреждением.
- **Деньги подписки — не сумма по API**: доля проекта = его взвешенная по прайсу стоимость / стоимость всех за период;
  деньги проекта = доля × платёж за период. Сырые токены на 98 % кэш-чтения и перекашивают картину. Абсолютные
  API-суммы как «деньги» Элвис снёс («какие-то сумасшедшие суммы, я же не по прайсу работаю», #2010) и вернул только
  строкой «если бы по API» («люди же любят понтоваться… и людей бы это отрезвляло», #2554).
- Проект чата: разметка Контекстолога → финальная строка ответа `✅Проект…` → папка транскрипта (`cwd`) → «Без проекта»
  (#2133: слепая зона с 58 % до 0,6 %). Один проект с разными маркерами склеивать по имени (#2546). Цвет — маркер-эмодзи
  (палитра Trelvis).
- Подписка: тариф из `~/.claude.json → oauthAccount.organizationRateLimitTier` (max_20x → $200); реальный платёж, налог
  (16 %) и день цикла — ручные настройки, `subscriptionCreatedAt` врёт при смене тарифа (#2131/#2596). История
  тарифов — список периодов.
- Лимиты 5 ч / неделя локально нигде не лежат — только statusline Claude Code (`rate_limits`) в терминале; правило
  «нет источника — полоску не рисуем, выдуманный процент запрещён» (#3175/#3381/#3838 — кругляшки у поля ввода).
- Время по проектам (#2179): отрезки между событиями с порогом тишины 10 мин, пересечения параллельных чатов делятся.
- Кэш разбора по `размер:mtime` файла; транскрипты Claude чистит — для истории по дням нужен свой накопитель.

## Откуда брать сегодня (проверено на этом Маке)

- `~/.claude/projects/<папка>/<sessionId>.jsonl` — `message.usage` (input, cache_creation с 5m/1h, cache_read,
  output, thinking) и `message.model`; субагенты — `<sessionId>/subagents/agent-*.jsonl`; **агенты воркфлоу** —
  `<sessionId>/subagents/workflows/wf_<runId>/agent-*.jsonl`, сам прогон — `<sessionId>/workflows/wf_<runId>.json`
  (runId, timestamp, meta.name, result) — прямой путь к «цене воркфлоу».
- `~/Library/Application Support/Claude/claude-code-sessions/*/*/local_*.json` — индекс чатов Desktop: `cliSessionId`
  (= имя jsonl), `cwd`, `title`, `model`, `effort` — PimpMyClaude его уже читает (`ProjectIndex`): «чат → папка →
  проект» без Контекстолога.
- Собственная сводка Claude `LocalSessions.getCodeStats` читает все транскрипты (9,5 с CPU) и без проектов — не брать.
