Что открывает клик

1. Клик по заголовку подсказки рекомендую

Клик по сегменту — как сейчас: открыть/закрыть подсказку. Клик по подчёркнутой первой строке «📄 PimpMyClaude · …» открывает docs/status.md этого проекта в обычном редакторе.

Промахнуться по полосе легко (она в две точки высотой), и промах не должен запускать программу.

2. Двойной клик по сегменту

Первый клик — подсказка, двойной — файл. Ничего подчёркивать не надо.

Двойной клик по полосе в две точки — попасть трудно; и заранее не видно, что он вообще есть.

3. ⌥-клик по сегменту

Обычный клик — подсказка, ⌥-клик — файл.

Про клавишу надо помнить; команде это придётся объяснять в инструкции.

Вопросы Элвису

1. Вид подсказки
  • (рекомендую) вариант А: имя проекта в заголовке, строка воркфлоу, «✋ Ждёт Элвиса», «Сейчас»
  • вариант Б — без строки «Сейчас»
  • вариант В — как сегодня, только значок ✋ в заголовке
2. Что кликаем, чтобы открыть status.md
  • (рекомендую) клик по заголовку подсказки — подсказка при этом остаётся открытой
  • двойной клик по сегменту
  • ⌥-клик по сегменту
3. В чём открывать файл
  • (рекомендую) в программе по умолчанию для .md (у тебя это редактор) — обычный «Открыть»
  • всегда в Finder, подсветить файл в папке
  • только показать путь в подсказке, открывать самому
4. Пункт «📊 Сводки ▸» в меню окна
  • (рекомендую) держать про запас: делаем, только если открывать файл прямо из подсказки не выйдет
  • сделать в любом случае — список проектов, клик открывает их status.md; это единственный способ, который точно заработает, и меню к этому времени свободно
  • не делать вовсе

Полоска, сегменты, цвета, места и клавиши не меняются. Сводки по-прежнему берутся из <папка проектов>/*/docs|audit|work/status.md раз в минуту; нет папки — нет и подсказки, всё остальное работает. Подсказка, как и сейчас, мышь не ловит — кликается только её первая строка. Открытие файла из страницы Claude — единственное место, которое надо проверить живьём до кодинга: если Claude не пускает такие ссылки наружу, останется вариант «показать путь» или пункт меню, а открытие уйдёт отдельной задачей.

Что от тебя нужно, чтобы начать: только ответ на вопрос 1. Вопросы 2–4 касаются одного открытия файла и ничего не задерживают — несрезанные сводки, точные номера и «✋ Ждёт Элвиса» делаются в любом случае. Команде это приедет следующим релизом: после замены приложения надо один раз нажать «Поставить снова», иначе полоска останется без подсказок.
