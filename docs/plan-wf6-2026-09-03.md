## Что есть после WF5

- `claude-patch/themes.json` — 9 тем (6 цветов + type). `inject.js` раздел «2а. Темы окна»: генератор CSS из палитры
  (порт ElvisOS + Epitaxy-блок + `--cds-*`), adoptedStyleSheets, ключ окна `main` / `w:<title>`, sessionStorage
  `{key, theme}` + localStorage карта `{key: theme | "none", "*": theme}`, команда
  `{action:"theme", scope:"window"|"all", title, theme|null}`.
- Swift: `ThemeCatalog` (бандл), `ThemeStore` (UserDefaults: `themeByWindow`, `themeAll`), подменю «Тема окна ▸» и
  «Тема всех окон ▸» в `MinimizeMenu`, `ClaudeActions.applyTheme`, `CommandChannel` с вложенным JSON.
- Разбор жалобы #5313 (22:00, по хранилищу): все четыре окна держат СВОИ темы (arctic/dracula/green + main violet),
  а `themeAll = violet` и карта `"*": violet` — то есть один раз была выбрана «Тема всех окон → Фиолетовая». Подменю
  стоят вплотную, при скольжении мыши вниз «Тема окна» сменяется на «Тема всех окон» — промах. Адресация по окну
  ошибок не показала. Лечится компоновкой меню, не логикой.

## Решение

1. **Каталог — все популярные цвета + темы «для девчонок»** (слово Элвиса 22:35: «побольше тем для девчат»), у каждой
   имя = цвет по-русски и кружок цвета в меню. Тёмные: Красная, Оранжевая, Жёлтая, Зелёная, Бирюзовая, Синяя,
   Фиолетовая, Розовая, Коричневая, Серая, Малиновая, Сиреневая + именные Matrix (ядовито-зелёная), Dracula
   (серо-фиолетовая), Tokyo Night (тёмно-синяя). Светлые (type light, мягкие, «не хакерские»): Светлая (id `arctic`),
   Лавандовая, Персиковая, Мятная, Пудровая, Сакура, Небесная, Кремовая, Лимонная — итого 24. В подменю «Тема»
   тёмные и светлые разделены разделителем с disabled-заголовками «ТЁМНЫЕ» / «СВЕТЛЫЕ». **id девяти существующих тем не
   менять** (ThemeStore и галки ключуются по id), меняются только name/palette. Светлые темы ставят `color-scheme:
   light` и светлую палитру во все слои (Epitaxy-блок в генераторе уже умеет `type: light`).
2. **Меню без промахов** — одно подменю «🎨 Тема ▸»: сверху «Мои темы» (если есть) → разделитель → цвета с кружками
   (NSImage 14 px: заливка background, ободок accent, `isTemplate=false`, свой конструктор, не `icon()`) → разделитель →
   «Как у Claude» (сбрасывает только тему) → разделитель → «Всем окнам ▸» (вложенное подменю с тем же списком и
   disabled-заголовком «ВСЕМ ОКНАМ» сверху, чтобы отличать) → «Сохранить как мою тему…» → «Удалить мою тему ▸».
   Отдельное подменю «Тема всех окон» убирается. Второе подменю «🔤 Шрифт ▸»: список шрифтов → «Как у Claude»
   (сбрасывает только шрифт) → «Всем окнам ▸» (с тем же заголовком). Параметры `MinimizeMenu.build` — одним struct.
3. **Шрифты — побольше, классные, включая моноширинные** (слово Элвиса 22:35). Белый список, отфильтрованный по факту
   установки (`NSFontManager.shared.availableFontFamilies`) и по кириллице (`NSFont(name:).coveredCharacterSet.contains("Ж")`):
   Системный (по умолчанию); обычные — Helvetica Neue, Avenir Next, Futura, Gill Sans, Optima, Georgia, Palatino,
   Baskerville, Didot, Hoefler Text, Iowan Old Style, Times New Roman, Verdana, Trebuchet MS, Arial, Tahoma,
   American Typewriter, Copperplate, Comic Sans MS, Chalkboard SE, Noteworthy, Marker Felt, Bradley Hand, Snell
   Roundhand, Papyrus; моноширинные (в отдельной секции «МОНОШИРИННЫЕ») — SF Mono, Menlo, Monaco, Courier New, Andale
   Mono, PT Mono + семейства по `\b(Mono|Code|Plex)\b` (JetBrains Mono, Fira Code, Cascadia, IBM Plex Mono, Source
   Code Pro — если стоят), не больше 10. Без кириллицы — не показывать. В меню — `localizedNameForFamily`, в команду —
   сырое имя. Каждый пункт шрифта рисуется своим шрифтом (`attributedTitle`), чтобы видеть, как выглядит.
   Шрифт — **второй `CSSStyleSheet` (`fontSheet`)**, независимый от темы: генератор темы не трогаем, шрифт без темы
   окно не красит. CSS: `--claude-themes-ui-font` + правило body/кнопки/поля как в ElvisOS
   (`claude-theme-manager.mjs:772`); `mono:true` → тот же шрифт и на код (`--font-mono`, code/pre); `mono:false` →
   `--font-mono` не трогать. При смене шрифта сбрасывать `state.natural` (кэш высоты поля, inject.js ~1248).
4. **«Мои темы»** — пара «встроенная палитра + шрифт» под своим именем, редактора цветов нет. Файл
   `~/Library/Application Support/MyClaude/my-themes.json`: `{version:1, themes:[{id:"user-<мс>", name, type, palette,
   font}]}` (палитра копируется из каталога по id при сохранении). Читать на каждый показ меню (не `static let`),
   битый файл → пустой список, меню живо. «Сохранить как мою тему…» берёт `ClaudeActions.lastApplied{Theme,Font}`
   (последняя команда из этого приложения; нет — алерт «сначала выбери тему»). Имя — NSAlert с полем: перед
   `runModal` `NSApp.activate(ignoringOtherApps:)`, `initialFirstResponder = field`, после — фокус окну Claude; имя
   ≤ 80 знаков (как `themeText`). Лимит 20 своих тем. Удаление — «Удалить мою тему ▸» (без ⌥-клика); удалённая, но
   применённая тема остаётся в окне без галки. Применение своей темы — одна команда с обоими слоями (`theme` + `font`).
5. **Контракт команды (менять только на гейте), побайтно, порядок полей `id, action, at, scope, title, theme, font`:**
   `{"id":"…","action":"theme","at":"…","scope":"window"|"all","title":"…","theme":{"id","name","type","palette":{"accent","background","foreground","sidebar","panel","muted"}},"font":{"id":"…","family":"SF Mono","mono":true}}`
   — поле `theme`/`font` есть → меняем этот слой; поля нет → слой не трогаем; `null` → сброс слоя. `family` — голое
   имя семейства (белый список `[A-Za-z0-9 -]`, ≤ 60 знаков), стек и кавычки дописывает страница; `mono` — булево
   (`CommandValue` получает `case bool`). Action остаётся `"theme"`.
   Хранилище страницы, трёхзначное по слою: sessionStorage `{key, theme: <объект>|"none"|<нет>, font: <объект>|"none"|<нет>}`,
   localStorage карта `{key: {theme, font}}` с той же трёхзначностью; **старый формат** (у значения есть `palette` на
   верхнем уровне → `{theme: значение}`; строка `"none"` → `{theme:"none"}`; сессия без `font` → шрифта нет) читается
   обязательно — иначе живые окна Элвиса потеряют темы на первом инжекте. `scope:"all"` чистит в карте ТОЛЬКО свой
   слой у каждой записи (тема «всем» не трогает шрифты окон и наоборот); Swift `clearWindowThemes()` — тоже по слою.
   Восстановление — по слою отдельно (session → window → "*"): тема окна + шрифт «для всех» — законно.
6. Галка в «Тема» у окна — по записи ThemeStore (как сейчас); в «Шрифт» — так же.

## Разбор плана (критик Opus max, 22:20: 27 правок, 5 критичных — все внесены выше)

Критичные: шрифт во втором CSSStyleSheet; `scope:"all"` чистит только свой слой; `CommandValue.bool`; шрифту свой
санитайзер и голое имя семейства; чтение старого формата хранилища. Прочее внесено в пункты 1–5.
Тесты, которые батч B обязан переписать поимённо (не ослабить): `testMenuHasTwoThemeSubmenus` → два подменю
«Тема»/«Шрифт» с вложенным «Всем окнам ▸» и заголовком; `testThemePayloadMatchesContract` и
`testThemeResetPayloadCarriesNull` → байт-в-байт payload для трёх случаев: только тема, только шрифт, оба; плюс сброс
одного слоя (`"font":null` без `theme`). `status()` страницы: `theme: {id, key, source}`, `font: {id, family, mono,
source}`, `raw` — сырая запись карты. README/TEAM.md (волна 2): раздел «Темы окон» — 24 темы, два подменю
«Тема»/«Шрифт», «Всем окнам» внутри, «Мои темы».

## Гейт

Тесты зелёные; у Элвиса: «Тема» с кружками и цветами, шрифт меняется в одном окне, «Мои темы» сохраняется и
применяется, «Всем окнам» только по явному выбору; после перезапуска Claude всё возвращается; релиз 1.2.0.
