## Что есть после WF5

- `claude-patch/themes.json` — 9 тем (6 цветов + type). `inject.js` раздел «2а. Темы окна»: генератор CSS из палитры
  (порт ElvisOS + Epitaxy-блок + `--cds-*`), adoptedStyleSheets, ключ окна `main` / `w:<title>`, sessionStorage
  `{key, theme}` + localStorage карта `{key: theme | "none", "*": theme}`, команда
  `{action:"theme", scope:"window"|"all", title, theme|null}`.
- Swift: `ThemeCatalog` (бандл), `ThemeStore` (UserDefaults: `themeByWindow`, `themeAll`), подменю «Тема окна ▸» и
  «Тема всех окон ▸» в `MinimizeMenu`, `ClaudeActions.applyTheme`, `CommandChannel` с вложенным JSON.
- Разбор жалобы #5313 (22:00, по хранилищу): все четыре окна держат СВОИ темы (arctic/dracula/green + main violet),
  а `themeAll = violet` и карта `"*": violet` — то есть один раз была выбрана «Тема всех окон → Фиолетовая». Подменю
  стоят вплотную, при скольжении мыши вниз «Тема окна» сменяется на «Тема всех окон» — промах. Адресация по окну
  ошибок не показала. Лечится компоновкой меню, не логикой.

## Решение

1. **Каталог — все популярные цвета**, у каждого имя = цвет по-русски и кружок цвета в меню: Красная, Оранжевая,
   Жёлтая, Зелёная, Бирюзовая, Голубая, Синяя, Фиолетовая, Розовая, Коричневая, Серая, Чёрная (почти чёрный фон),
   Белая (светлая) + именные: Matrix (ядовито-зелёная), Dracula (серо-фиолетовая), Tokyo Night (тёмно-синяя).
   Палитры «заметные»: фон явно окрашен, но тёмный (как violet/blue/green/orange после правки 21:40), акцент ярче.
   Для светлых (Белая) — type light.
2. **Меню без промахов** — одно подменю «🎨 Тема ▸»: сверху «Мои темы» (если есть) → разделитель → цвета с кружками
   → разделитель → «Как у Claude» → разделитель → «Всем окнам ▸» (вложенное подменю с тем же списком) →
   «Сохранить как мою тему…». Отдельное подменю «Тема всех окон» убирается. Второе подменю «🔤 Шрифт ▸»: список
   шрифтов → «Как у Claude» → «Всем окнам ▸».
3. **Шрифты** — список из установленных на Маке (проверять `NSFontManager.shared.availableFontFamilies`):
   Системный (по умолчанию), SF Mono, Menlo, Monaco, Helvetica Neue, Avenir Next, Georgia, Iowan Old Style,
   Palatino, Times New Roman, Courier New, Comic Sans MS, Verdana, Trebuchet MS + всё из семейств, содержащих
   Mono/Code (JetBrains Mono, Fira Code, Cascadia, если стоят). Шрифт — отдельный слой поверх темы: у окна
   `theme` и `font` независимы (можно шрифт без темы). CSS: `--claude-themes-ui-font` и правило на body/кнопки/поля
   как в ElvisOS (`claude-theme-manager.mjs:772`), код-шрифт не трогаем (моно-шрифт выбран → он же на код).
4. **«Мои темы»** — файл `~/Library/Application Support/MyClaude/my-themes.json`: `{version:1, themes:[{id:"user-<мс>",
   name, type, palette, font}]}`. «Сохранить как мою тему…» берёт текущие тема+шрифт ОКНА (из ThemeStore по
   заголовку; если записи нет — из последней команды), спрашивает имя (NSAlert с полем), пишет файл. В подменю
   «Мои темы» — свои темы с кружком; ⌥-клик или пункт «Удалить мою тему ▸» — удаление. Применение — как обычная тема
   (палитра + font в одной команде).
5. **Контракт команды (менять только на гейте):**
   `{"id","action":"theme","at","scope":"window"|"all","title","theme":{id,name,type,palette}|null|<нет поля>,
   "font":{"id","family":"<CSS font-family>","mono":true|false}|null|<нет поля>}` — поле есть → меняем этот слой;
   поля нет → слой не трогаем; null → сброс слоя. Хранилище страницы: sessionStorage `{key, theme, font}`,
   localStorage карта `{key: {theme, font} | …}`; старый формат (тема без обёртки) читать как `{theme}`.
6. Галка в «Тема» у окна — по записи ThemeStore (как сейчас); в «Шрифт» — так же.
