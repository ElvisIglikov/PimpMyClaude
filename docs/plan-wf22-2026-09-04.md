## Решения

### 1. Контракт команды `status` v2 (новый, обязателен побайтно)

Порядок полей фиксирован: у проекта — `name`, `path`, `now`, `wait`, `items`; у пункта — `n`, `text`.

```json
{"id":"…","action":"status","at":"…","scope":"all","projects":[
  {"name":"PimpMyClaude",
   "path":"/Users/elvis/_ElvisProjects/PimpMyClaude/docs/status.md",
   "now":"WF14 кодится; планы и макеты WF15–WF24 пишутся",
   "wait":"",
   "items":[{"n":22,"text":"⬜ · полоска v3: 9+ проектов, «ждёт Элвиса», клик открывает status.md · планирование"}]}
]}
```

- `name` — имя папки проекта, как сейчас. `path` — абсолютный путь к найденному `status.md`; страница показывает его
  подписью и, если разведка выберет П2, открывает по нему. **Приложение путь со страницы обратно не принимает** (п. 4).
- `now` / `wait` — текст после «Сейчас:» и «Ждёт Элвиса:», **последнее вхождение** в файле, без префикса, ≤240 знаков.
  Значения «ничего», «нет», «—», «-», пустое — превращаются в `""` (страница пустое поле не рисует).
- `items` — по одному на блок «N️⃣ Workflow», в порядке файла, не больше 40 (`PROGRESS_SEG_MAX` страницы).
  `n` — число (`CommandValue.number`), разобранное из ЦЕПОЧКИ клавиш-цифр: «2️⃣2️⃣» → 22, «🔟» → 10, «1️⃣0️⃣» → 10.
  `text` — «значок · о чём · роли через ` · `», номера в нём нет, ≤120 знаков с многоточием, роли — не больше шести
  (правила ровно те, что сегодня в `statusLine`, inject.js:1490).
- Поля `text` у проекта (старый сырой markdown) больше нет. Страница читает `items`; их нет, а `text` есть — работает
  по-старому (запасная ветка на случай, когда приложение новее живого `inject.js`).

### 2. Лимиты и порядок (задача «9+ проектов»)

| | было | стало |
|---|---|---|
| на проект | 6 КБ сырого markdown | 4 КБ уже сжатой записи |
| всего | 32 КБ | **64 КБ** |
| проектов | 24 (страница) | 48 |
| блоков на проект | первые 6 КБ, потом последние 12 | последние 40 подряд |
| порядок отбора | алфавит | **по mtime `status.md`, свежие первыми** |

- 64 КБ безопасны: лоадер отдаёт команду через `executeJavaScript` раз в 60 с и только при смене содержимого
  (`sentDigest`), а разбор на странице после сжатия сводится к сборке Map — построчного разбора там больше нет.
  На гейте замерить `performance.now()` вокруг `runStatusCommand` при 9+ проектах.
- Порядок по mtime меняет только, кого выбрасывать при переполнении; страница ищет по имени и порядка не замечает.
- `slice()` и `isWorkflowHeading` из старого пути остаются (их зовёт разбор блоков), но 6-килобайтного среза
  сырого текста в команде больше нет.

### 3. Подсказка: имя проекта, «Ждёт Элвиса», перенос строк (раздел 2б inject.js)

Вид — по макету, вариант выбирает Элвис (вопрос 1). Рекомендуемый:

```
📄 PimpMyClaude · воркфлоу 22 из 24 · идёт      ← заголовок, кликабельный
⬜ · полоска v3: 9+ проектов, «ждёт Элвиса»… · планирование
✋ Ждёт Элвиса: ответы на вопросы 1–4 макета    ← только если непусто
Сейчас: WF14 кодится; планы WF15–WF24 пишутся   ← только если непусто
```

- Заголовок несёт имя проекта: сегодня по подсказке не понять, чей это марафон.
- «Ждёт Элвиса» — отдельной строкой, значок ✋ и жёлтый `#f5c542` (тот же, что у ждущего сегмента, `PROGRESS_PAINT.wait`).
- `white-space` меняется с `pre` на `pre-wrap`: строки «Ждёт Элвиса» у VkusnoffKz-deploy длиной в 160 знаков, при
  `pre` они уезжают за 560 px и обрезаются `overflow:hidden`.
- Сводки по этому номеру нет — как сейчас, одна строка «Воркфлоу N · состояние», плюс подвал, если он есть.
- Заодно в том же файле чинятся пп. 4 и 5 «Что выяснено»: номер приходит полем `n` (разбор клавиш уезжает в Swift),
  а имя проекта сопоставляется **сначала точным совпадением ключа, префиксом — только если совпадение одно**.

### 4. Клик открывает status.md

Что кликаем — вопрос 2 (рекомендую: **заголовок подсказки**; сегмент по-прежнему только открывает и закрывает
подсказку, чтобы промах по узкой полосе не запускал внешнюю программу).
Чем открываем — вопрос 3, по итогам микро-разведки:

- **П1 (лучший): своя URL-схема.** `Info.plist` → `CFBundleURLTypes` со схемой `pimpmyclaude`; страница делает
  `location.href = "pimpmyclaude://open?project=" + encodeURIComponent(name)`. Приложение (новый `StatusOpen.swift`)
  ловит URL, **само** ищет `<projectsRoot>/<имя>/{docs,audit,work}/status.md` и открывает `NSWorkspace.shared.open`.
  Безопасность: принимается только `open`, только параметр `project`, имя без `/`, `\` и `..`, файл ровно `status.md`,
  результат обязан лежать внутри `projectsRoot` (сверка по `standardizedFileURL.path.hasPrefix`); всё прочее молча
  игнорируется. Путь со страницы не принимается никогда.
- **П2: `window.open("file://" + path)`** — без Swift вовсе, открывает система. Берём, если П1 не пустили, а file:// пустили.
- **П3: хэш в адресе.** Страница ставит `#myclaude-open=<имя>` через `replaceState(history.state, …)`, приложение раз
  в 2 с читает `status.json` лоадера, видит хэш в `webContents[].url`, открывает файл; страница хэш снимает через
  секунду. Задержка до 2 с, роутер задет — берём последним.
- **Ни один не годится** — открытие переносится задачей в 🟣Trelvis, а в подсказке остаётся строка с путём (её можно
  выделить и скопировать). Пункт меню «📊 Сводки ▸» — вопрос 4, по умолчанию НЕ делаем: `MinimizeMenu.swift`
  перестраивают WF14 и WF19, лезть туда третьим прогоном незачем.

### 5. Один писатель на файл

- `claude-patch/inject.js` — **батч A, один агент**, разделы 2б и «сводка проектов». Больше в файл в эту волну не пишет никто.

- **WF22 не стартует, пока `MinimizeMenu.swift`/`MenuModel.swift` заняты** (WF14 идёт, WF19 запланирован) и пока
  WF14 не слит в `main`: тесты и `AppDelegate` общие. Перед стартом — проверка кронов и `run-*.json` в `docs/`.

### 6. Не делаем в WF22

Лоадер; разбор строки состояния (`PROGRESS_RE`) и геометрию полосы; свою читалку markdown внутри Claude; хранение
сводки в localStorage; пункт меню «Сводки ▸», если Элвис не попросит (вопрос 4); настройку `projectsRoot` из интерфейса
(это WF15, «цвет и оформление проекта из его папки», — с ним же согласовать, кто владеет `projectsRoot`).

## Открытые риски

- **Микро-разведка может закрыть все три пути** (Claude не пускает ни чужую схему, ни `file://`, а хэш дёргает роутер).
  Тогда «клик открывает» из WF22 выпадает — остаются сводки и «Ждёт Элвиса», а открытие уходит задачей в 🟣Trelvis.
  Решать это на гейте до батчей, а не после.
- **URL-схема — новая поверхность.** Любая страница в любом браузере сможет дёрнуть `pimpmyclaude://`. Поэтому только
  `open?project=<имя>`, только внутри `projectsRoot`, только файл `status.md`; всё остальное игнорируется молча.
  Verify обязан проверить обход по `..`, абсолютный путь в параметре и симлинк наружу.
- **Смена контракта рвёт пару «приложение ↔ живой inject.js».** Новое приложение со старой страницей = подсказка без
  сводок. Гейт кладёт оба файла одной операцией; в run-файл — строка, что откат тоже парный.
- **Свой формат `status.md`.** Файл Элвис правит руками, и разбор в Swift обязан переживать мусор: блок без пунктов,
  два «Ждёт Элвиса», номер словом, эмодзи без вариационного селектора («2⃣»). Тесты на каждый случай обязательны.
- **64 КБ через `executeJavaScript` в каждую страницу.** Раз в минуту и только при изменении, но при 9+ проектах и
  четырёх открытых окнах это ощутимая работа — замер на гейте, порог поднимать не «на глаз».
- **Подсказка перестаёт быть прозрачной для мыши** (у заголовка появляется `pointer-events`). Проверить, что клик мимо
  и Escape по-прежнему закрывают её, что выделение текста ленты под ней не ломается и что она не перехватывает
  прокрутку.
